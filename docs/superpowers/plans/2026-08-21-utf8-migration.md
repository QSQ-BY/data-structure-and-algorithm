# UTF-8 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Convert every project-maintained text file to UTF-8 without BOM and configure VS Code to keep using UTF-8.

**Architecture:** Preflight-decode all files before writing, create an external byte-for-byte ZIP backup, then rewrite decoded text with strict UTF-8 without BOM. Verify every file by strict decoding and Unicode-content equality.

**Tech Stack:** Windows PowerShell, .NET text encoders and ZIP APIs, EditorConfig, VS Code JSONC

## Global Constraints

- Work only under D:/code/data structure and algorithm.
- Exclude .git and .build from conversion.
- Preserve all decoded characters and line endings.
- Decode existing files as UTF-8 BOM, strict UTF-8, or strict CP936.
- Stop before writing if any file cannot be decoded.
- Back up original bytes under D:/codex.
- Do not commit converted files because unrelated user changes already exist.

---

### Task 1: Backup and preflight

**Files:**
- Read: all project files outside .git and .build
- Create: D:/codex/data-structure-and-algorithm-utf8-backup-yyyyMMdd-HHmmss.zip, where the suffix is generated by Get-Date

**Interfaces:**
- Consumes: original project bytes
- Produces: recoverable ZIP backup and an in-memory decoded-text snapshot

- [ ] Run strict preflight over every in-scope file and reject NUL bytes or undecodable bytes.
- [ ] Create a ZIP whose entry names are project-relative paths and whose entry data is the original bytes.
- [ ] Record .build file hashes before changing project text.

Expected: all files classify as UTF-8 BOM, UTF-8, or CP936; the backup ZIP opens and has one entry per in-scope file.

### Task 2: Configure future UTF-8 opens and saves

**Files:**
- Create: D:/code/data structure and algorithm/.editorconfig
- Modify: D:/code/data structure and algorithm/.vscode/settings.json

**Interfaces:**
- Consumes: approved UTF-8 design
- Produces: persistent UTF-8 editor defaults

- [ ] Create .editorconfig with exactly:

~~~ini
root = true

[*]
charset = utf-8
~~~

- [ ] Add these properties after the opening brace of .vscode/settings.json:

~~~json
  "files.encoding": "utf8",
  "files.autoGuessEncoding": false,
~~~

- [ ] Parse settings.json after removing its full-line JSONC comments and verify both values.

Expected: EditorConfig selects utf-8 and VS Code selects utf8 with guessing disabled.

### Task 3: Convert and verify

**Files:**
- Modify: every text file outside .git and .build

**Interfaces:**
- Consumes: the decoded-text snapshot from Task 1 plus the new configuration
- Produces: strict UTF-8 files without BOM

- [ ] Re-enumerate and strictly preflight all in-scope files after adding configuration.
- [ ] Rewrite each decoded string with System.Text.UTF8Encoding(false, true).
- [ ] Verify every file strictly decodes as UTF-8, does not start with EF BB BF, and equals its pre-write decoded string.
- [ ] Verify no U+FFFD replacement character was introduced.
- [ ] Verify .build hashes are unchanged.
- [ ] Force-read representative old and new Chinese files as UTF-8.
- [ ] Run the rectangle Python sample and expect 152.
- [ ] Show git status without staging or committing the bulk conversion.

Expected: every in-scope text file is UTF-8 without BOM, Chinese is readable, .build is unchanged, and the sample still outputs 152.
