# 国王游戏：手写大整数实现设计

## 目标

修复 `source/sort_algorithm/exercise/hz256_king_game.cpp` 中的手写 `BigInt`，让国王游戏在前缀乘积超过内建整数范围时仍能正确输出最大赏金。

## 范围

保留十进制、低位在前的 `vector<int>` 存储方式，只实现本题需要的操作：从非负 `int` 构造、乘以非负 `int`、除以正 `int`、大小比较和十进制输出。`main` 只运行大整数版本。

不改动大臣按 `left[i] * right[i]` 升序排列的贪心策略。

## 实现

- `normalize()` 处理每一位进位并删除最高位多余的零，保证零表示为单个 `0`。
- `operator*=(int)` 逐位相乘后规范化。
- `operator/(int)` 从最高位到最低位做长除法，返回商且不修改被除数。
- `operator>` 先比较位数，再从最高位比较数值。
- 输出运算符作为非成员函数，按从最高位到最低位输出。
- 大整数版本按“先计算当前大臣赏金，再把其左手数乘入前缀”的顺序更新答案。

## 验证

编译时开启 `-Wall -Wextra -pedantic`；运行题目样例，并覆盖：商为零、连续进位和高于 32 位整数范围的乘积。
