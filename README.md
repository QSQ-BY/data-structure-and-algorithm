# 数据结构与算法学习记录

这个仓库记录了我从零开始学习数据结构与算法的过程。

`source` 里放的是每一章的代码：一部分是基础数据结构的定义和常见操作，另一部分是配套练习。练习主要来自 LeetCode、洛谷等 OJ 网站，也有跟着课程完成的题目。`codeforces` 单独保存参加正式比赛或 virtual participation 时写下的代码和复盘。`diary` 里则是我每天写完代码后的复盘，记录当天学了什么、卡在哪里，以及后来是怎么想明白的。

这里不只收集最后能够运行的代码。我更想保留学习过程中那些逐渐连起来的线索：顺序表为什么要区分容量和元素个数，链表题为什么总是在找指针关系，括号匹配如何把栈从一个结构体变成一种思考方式，递归又是怎么在二叉树里真正派上用场的。

## 怎么阅读这个仓库
