## B Polyline：公共端点只算一个交点

折线与水平线 `y=K` 的交点可能在线段内部，也可能恰好是原折线顶点。内部交点只属于一条线段，内部顶点却由左右两条线段共享，逐段统计时会重复。

我保留的实现先按线段统计，再修正端点：

```python
ans = 0
for i in range(n-1):
    a = arr[i]
    b = arr[i+1]
    if(a>b):
        a,b = b,a
    if(a<k<b):
        ans += 1
    if(a == k or b == k):
        ans += 1
if(arr[0] == k):
    ans += 1
if(arr[-1] == k):
    ans += 1

print(ans - arr.count(k))
```

严格夹在两端高度之间时，线段内部贡献一个点。端点高度等于 `K` 时，这条线段也贡献一次。内部的目标顶点被两条线段计了两次，最后减一次就剩一个；整条折线两端的目标顶点则先额外加一次，再统一减一次，也恰好保留一个。

约束保证相邻顶点高度不同，没有整段与水平线重合的情况。当前统计为 $O(N)$。这里数的是几何位置上的点，不能把每条线段自己的端点记录当成不同对象。

## D Autopilot：免费边放队首，付费边放队尾

每个点的出边中，终点编号最小的那个目的地可以免费到达，其他目的地需要一单位燃料，原图因此可以看成边权只有 0、1 的最短路问题。

代码先排序邻接表，让第一个邻居对应免费移动，再用双端队列维护搜索顺序：

```python
for index, nxt in enumerate(g[cur]):
    if index == 0:
        new_dist = step
    else:
        new_dist = step + 1

    if dist[nxt] <= new_dist:
        continue
    dist[nxt] = new_dist
    if index == 0:
        q.appendleft((new_dist, nxt))
    else:
        q.append((new_dist, nxt))
```

免费移动不增加燃料，放队首；付费移动增加 1，放队尾。`dist` 保存最少燃料，严格改进才入队，弹出后跳过失效的旧状态。

比较的是燃料，而不是经过的边数。免费移动可能绕很多步，也可能成环，普通的第一次看到一个点就永久标记，不能代替这里的距离松弛。

0-1 BFS 部分为 $O(N+M)$；当前实现还排序了邻接表，排序成本为 $O(\sum_u deg(u)\log deg(u))$。

## F Evil Shortest Path：相同前缀的节点一起扩展

路径分数由边上数字拼接而成。数字都在 1 到 9 之间，位数少的正整数一定更小；位数相同时，再按字典序比较。所以可以先按路径长度分层，再保证同一层中的前缀顺序。

只把每个节点的出边排序，还不足以保证全局顺序。题面第一个样例里，两个节点的最优前缀都是 `1`：先处理某个节点，可能先生成 `19`，另一个节点却还能生成 `12`。第一次生成就标记目标，会留下错误答案。

当前实现让队列元素保存同一个真实最优前缀对应的一组节点。先收集整组节点的出边，按数字分桶，再统一从 1 到 9 扩展：

```python
# 按数字从小到大扩展
# 这样就能保证队列取出元素都是按照从小到大进行取数的
for c in range(1, 10):
    new_group = []
    new_score = (score * 10 + c) % MOD

    for v in buckets[c]:
        if vis[v]:
            continue

        vis[v] = True
        ans[v] = new_score
        new_group.append(v)
    if new_group:
        q.append((new_group, new_score))
```

组内前缀相同，桶号较小的新前缀一定更小；不同组已经按长度和前缀顺序出队，因此第一次确定某个点时，得到的是最小拼接整数。相同桶中的目标点继续组成一个组，让下一轮保持这个条件。

`new_score` 只保存答案的模值。真实大小顺序由层次、分组、桶号保证，不能比较两个模值，也不能因为模值相同就合并两个不同的真实前缀。每个点只确定一次，每条边扫描一次，桶数固定为 9，时间和空间都为 $O(N+M)$。

D 和 F 都用了双端队列，但需要维持的关系不同。D 靠 0、1 边权安排距离顺序；F 需要把相同前缀的整个节点组作为一次扩展单位。只记住容器名称，会漏掉它们各自依赖的顺序条件。
