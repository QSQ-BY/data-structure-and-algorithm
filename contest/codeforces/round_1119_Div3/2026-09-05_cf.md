今天参加了一场新的 CF Div. 3，一共做了三道题。前两道都算比较简单，就不展开了：A 题按长度分组检查，B 题观察反复减二取绝对值后的变化，把奇数、模 4 余 0 和模 4 余 2 的数分开统计。

源码：[A. Moo Language School](A_Moo_Language_School.py)、[B. Minus Two](B_Minus_Two.py)、[C. 101](C_101.py)。

C 题把我难住了。想了很久，也没有找到一个明确的算法思路。后来注意到题目要求最大的可满足长度 $k$，很有一种二分答案的味道，于是没再细想，就一股脑开始写了。

## 长度更大，不代表判定具有单调性

题目给一个只含 `-1、0、1` 的数组，可以把 `-1` 替换成 `0` 或 `1`。我要让某个连续子数组尽可能长，并且两端都是 `1`，中间全是 `0`。长度为 1 的单独一个 `1` 也合法。

我当时写的 `check(k)`，判断的是“是否存在长度恰好为 $k$ 的合法区间”。直觉上区间越长越难满足，但这里的两个端点也有要求，缩短区间后，新端点可能正好落在固定的 `0` 上。

例如：

```text
原数组：-1 0 0 -1
可构造： 1 0 0  1
```

长度 4 可以满足，长度 3 和长度 2 却都不行，因为每个这样的窗口至少有一端是固定的 `0`。长度 1 又可以满足，所以按长度排列的判定结果是：

```text
k：       1      2      3      4
check： True  False  False  True
```

这就不是能直接二分的单调 01 模型。检查长度 3 失败后，把长度 4 一起排除，恰好会丢掉最优解。我这次在写代码之前漏掉的，就是对这个判定函数本身的检查。

如果把判定换成“是否存在长度至少为 $k$ 的合法区间”，它确实具有单调性，但如何高效检查仍然需要推导。这题直接扫描就能求出最长区间，没有必要再绕一层二分。

## 双指针：让固定的 1 成为新的左端点

后面问了 AI，才把这道题搞明白。把条件重新写出来之后，需要维护的东西清楚了：两端不能是原数组中的 `0`，中间不能有原数组中固定的 `1`。

右指针 `r` 一直向右走，左指针 `l` 保存当前能选的最靠左端点。遇到 `0` 时，它只能放在区间内部，跳过即可。遇到 `-1` 时，可以把它当作右端点尝试更新答案，但不必移动 `l`；以后继续向右扩展时，这个 `-1` 仍然可以填成 `0`。

遇到固定的 `1` 则要先更新答案，再把 `l` 移到当前位置。它可以结束前面的区间，但后续区间不能跨过它，否则内部就会出现一个无法修改的 `1`。

当前源码中的扫描部分是：

```python
    for r in range(n):
        if arr[r] == 0:
            continue
        # 第一次遇到能作为端点的位置
        if l == -1:
            l = r
        # 将当前位置作为右端点
        if r - l + 1 > best_len:
            best_len = r - l + 1
            best_l, best_r = l, r
        # 固定的 1 不能成为后续区间的内部元素
        if arr[r] == 1:
            l = r
```

对一个确定的右端点，只要区间内部没有固定的 `1`，左端点越靠左越好。固定的 `1` 出现时，更早的左端点又都不能继续使用，因此将 `l` 更新到这里就足够了。这是双指针扫描里用到的贪心选择。

例如 `[-1, 0, 1, -1, 0, 0, 1]`，下标从 0 开始。扫描到下标 2 的 `1` 时，先用 `[0, 2]` 更新答案，再令 `l = 2`；遇到下标 3 的 `-1` 时保留这个左端点，最后就能找到 `[2, 6]`，长度为 5。

找到最佳区间后，先把所有 `-1` 置为 `0`，再把最佳区间两端设为 `1`，原本固定的值保持不变。全零数组没有可用端点，得分就是 0；只有一个可用端点时，也能得到长度 1。整个算法扫描两遍数组，时间复杂度为 $O(n)$，除输入数组外只需要 $O(1)$ 的额外空间。

这题的实现不长，但从题面想到这样的双指针模拟和贪心，对我来说并不容易。回头看，我在“求最大长度”这几个字上停得太早了，还没有检查区间缩短后端点会怎样，就已经开始套二分。以后再有这种感觉，我想先找两个相邻长度试一试，确认较长的可行解能不能推出较短的可行解，再决定往下写。C 题虽然卡了很久，但这个反例和左指针的移动理由都值得留下来反复看。
