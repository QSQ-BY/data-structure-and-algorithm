## P13889：先横向取极值，再纵向取极值

[源码](../../Exercise/monotonic_queue&stack/P_13889_蓝桥杯_2023_省_Python_A_子矩阵.py)

子矩阵要把所有 a×b 窗口的最大值与最小值乘积相加。逐个窗口扫描会反复查看相同元素。我先沿每一行做宽度 b 的滑动窗口，保存 `row_min` 和 `row_max`，再对这两个结果按列做高度 a 的窗口。

最大值满足“每行先取最大，再从这些最大值里取最大”，最小值也一样，因此两次一维窗口正好给出二维窗口的极值。

当前入口是 `test02()`。下面摘录第二遍扫描中队尾维护的部分，过期下标已在前面的分支移除：

```python
            while(qmin and row_min[qmin[-1]][column_index] > number1):
                qmin.pop()
            while(qmax and row_max[qmax[-1]][column_index] < number2):
                qmax.pop()

            qmin.append(window_right)
            qmax.append(window_right)

            if(window_right - a + 1 >= 0):
                maximum = row_max[qmax[0]][column_index]
                minimum = row_min[qmin[0]][column_index]
                ans += maximum*minimum
                ans %= MOD
```

最小值队列对应的数值非递减，最大值队列非递增。新来的元素如果更优，队尾那些更差又更早过期的候选就不会再成为答案，可以直接弹出。队列保存下标，才能同时判断值和是否还在窗口内。

同一个下标在一遍扫描里只入队一次、出队至多一次。横向和纵向两遍总时间 O(nm)，当前实现保存原矩阵以及两张中间表，空间 O(nm)。等值元素在 `test02()` 中会一起保留，不影响队首极值和线性复杂度。

这里真正可以复用的是极值的分解方式：矩形上的 max、min 能按维度分两遍算，再把每个窗口对应的两种结果相乘取模。

## P10914：状态保存可达权值，而不是一条路径的分数

[源码](../../Exercise/dynamic_programming/P_10914_蓝桥杯_2024_国_B_跳石头.py)

这道蓝桥杯跳石头可以从 i 跳到 i+c[i] 或 2i。得分取所有可能到达的石头上的不同权值数量，不要求这些石头出现在同一条路径里。因此不能把两个后继的“分数”直接相加，重复权值需要去重。

我用整数的第 v 位表示权值 v 是否可达。`dp[i]` 的实际含义是从 i 出发的可达权值集合，而不是石头下标集合。两个目标都比 i 大，所以按下标倒序计算：

```python
for i in range(n,0,-1):
    dp[i] = (1<<arr[i])
    if(2*i <=n):
        dp[i] |= dp[2*i]
    if(i + arr[i] <= n):
        dp[i] |= dp[i+arr[i]]
for state in dp:
    ans = max(ans,state.bit_count())
print(ans)
```

先置上当前位置的权值位，再把合法后继的集合按位或进来。`bit_count()` 就是不同权值的数量。路径汇合、同一个权值出现在不同石头上，都由集合并集自然去重。

位运算把逐元素集合合并交给整数底层完成，但一个整数可能包含 O(n) 位，不能把每次按位或当成固定成本。设机器字长为 w，位集合运算的工作量上界可写作 O(n⌈n/w⌉)，存储最坏也需要 O(n⌈n/w⌉) 个机器字。

我把这题和最长路区分开：最长路选一个后继继续走，这里的题意要求汇总所有分支，所以状态必须能表达并集。

## P2105：把对角线编号平移成当前行的列编号

[源码](../../Exercise/simulation/P_2105_K皇后.py)

K 皇后的棋盘边长可以到两万，逐格存布尔矩阵开销很大。我分别用整数保存被占用的行、列以及两种对角线，再按行统计未被攻击的列。

坐标从 1 开始时，列 y 对应第 y-1 位；两种对角线分别用 x+y-2 和 y-x+n-1 编号。固定第 r 行后，前一种对角线编号减去 r-1，后一种减去 n-r，恰好都变成列编号 y-1。

```python
for r in range(1, n + 1):
    if row_state & (1 << (r - 1)):
        continue  # 这一整行都被攻击
    attacked = (
        column_state
        | (diagonal_state >> (r - 1))
        | (back_diagonal_state >> (n - r))
    )
    ans += (full & ~attacked).bit_count()
```

被皇后占据的整行直接跳过。其他行把列攻击、两种对角线平移后的攻击按位或起来，再用 `full & ~attacked` 截出棋盘内没有被攻击的位置。

Python 的按位取反作用在无限符号扩展的整数上，因此 `full` 这个只含 m 个 1 的掩码有明确用途：限制统计范围，不能直接对取反结果计数。

这里只保存常数个长度 O(n+m) 位的大整数。每行仍需处理一整段位集合，按机器字计，扫描约为 O(n⌈(n+m)/w⌉)，而不是 O(n) 的普通整数运算。我复习时需要重新推一遍两个移位量，确保对角线最终落到同一套列坐标上。
