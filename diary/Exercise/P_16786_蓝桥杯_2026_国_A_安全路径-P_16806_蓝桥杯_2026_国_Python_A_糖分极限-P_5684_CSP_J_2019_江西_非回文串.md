## P16786 安全路径：先筛掉不平稳节点，再按连通块计数

[源码](../../Exercise/graph_theory/P_16786_蓝桥杯_2026_国_A_安全路径.py)

以 1 为根算完子树大小后，只有大小为偶数的节点可以出现在安全路径上。在树中，两点之间的简单路径唯一，因此保留下来的每个连通块都可以单独统计。

 当前实现先用 order 记录父子顺序，再反向累计子树大小和连通块大小。下面是最终统计：

```python
for u in reversed(order):
    if size[u] % 2 == 0:
        dp[u] += 1
        p = parent[u]

        if p != 0 and size[p] % 2 == 0:
            dp[p] += dp[u]
        else:
            ans += dp[u] * (dp[u] - 1)
```

dp[u] 累计当前偶数子树节点连通块的规模。父节点也符合条件就向上合并；父节点不符合，或已经到根，当前块就结束，贡献为 s(s-1)。

 这里统计有序路径，所以 x→y 和 y→x 分开算，不除以 2。反向遍历代替递归，也避免深链时递归过深。三次线性处理，总时间和空间都是 O(n)。

## P16806 糖分极限：把一次减半操作放在两个可达闭包之间

[源码](../../Exercise/dynamic_programming/P_16806_蓝桥杯_2026_国_Python_A_糖分极限.py)

直接建状态时，需要同时记录当前糖分和减半操作是否用过。源码也保留了这种 BFS 解法：状态为 (i,used)，吃甜品留在原层，减半从未使用层进入已使用层。

 solution2 把过程分成三段：先算只吃甜品的全部可达值，再把这些值减半作为新起点，最后继续做一次吃甜品的可达扩展。两次吃甜品的扫描都从小到大，因为加 a、加 b 只会转移到更大的糖分。

 中间减半也从小到大扫描。新写入的 i//2 位于已经处理过的位置，不会在这一阶段再次被减半；0 减半仍是 0。这使一维数组可以同时保留不用减半和恰好用过一次减半的可能性。

 每个阶段都是 O(n)，空间 O(n)。一次性操作的状态可以用两层表示，也可以把所有使用时刻统一收集成第二阶段的起点。

## P5684 非回文串：先按字母形状计数，再放回不同编号

[源码](../../Exercise/math/P_5684_CSP_J_2019_江西_非回文串.py)

这道题里我追问过：既然每个字母都看成不同的编号，为什么算回文时还要考虑重复字母？

 总排列数确实是 n!。但一个排列是否回文，要看对应的字母是否对称，编号不同的两个 a 仍可以放在镜像位置。先数不同的回文字母串，再给同字母的位置分配编号，正好把这两层区分开。

 设字母频次为 c_i。如果奇数频次的字母超过一种，就无法构成回文；否则回文字母串数量为 (n//2)! / ∏(c_i//2)!，每种字母的编号又有 c_i! 种安排。源码先算左半边排列，再乘回这些编号排列：

```python
cnt = [0]*(26)
for ch in string:
    number = ord(ch) - ord("a")
    cnt[number] += 1
ans = factorial(n)

if(sum(c%2 for c in cnt) <= 1):
    left = factorial(n//2)
    for c in cnt:
        left //= factorial(c//2)
    palindrome = left
    for c in cnt:
        palindrome *= factorial(c)
    ans -= palindrome
```

例如 aba 有 6 种编号排列，其中两个不同编号的 a 可以互换，仍然得到回文，因此回文编号排列有 2 种，非回文为 4。

 答案为 n! 减去回文编号排列数，代码使用大整数精确整除后再统一取模，避免把带除法的式子直接混进模运算。这里需要记住的是计数对象有两层：字母决定形状，编号决定同一种形状对应多少个排列。
