## P4290 玩具取名：一个区间可能有多个来源，也可能没有来源

从一个字母出发，每次把一个字母替换成两个。逆着看，要判断左右两段能否分别来自某两个字母，再通过一条规则合成一个来源。

我把 `dp[l][r]` 定义成能够生成 `name[l:r+1]` 的所有字母组成的集合。长度为 1 时只包含这个字符本身，因为替换会增加长度。其他区间可能有多个来源，也可能是空集合，并不要求每段都能由一个字母生成。

规则也反向保存，从原字母到字母对，改成字母对到所有可能的原字母：

```python
for letter, rules in zip("WING", (w, i, n, g)):
    for pair in rules:
        if pair not in parents:
            parents[pair] = set()
        parents[pair].add(letter)
```

同一个字母对可能属于多条规则，必须累计来源。集合的元素代表不同的来源候选，并非字符串里依次排列的字符。这也回答了我追问的顺序问题：左右顺序由区间位置和 `a+b` 保证，集合先遍历哪个候选不影响结果。

```python
for k in range(l, r):
    #分别遍历可以生成左右两个部分的字母集合
    for a in dp[l][k]:
        for b in dp[k + 1][r]:
            pair = a + b
            origins = parents.get(pair, ())
            #可以理解为列表中的extend，往集合里面加入多个数字
            dp[l][r].update(origins)
    # 四个字母都已找到，不需要继续枚举分界点
    if len(dp[l][r]) == 4:
        break
```

`k` 把区间分成左右两段。`a`、`b` 分别来自左右集合，`parents.get(pair,())` 找出所有原字母，再用 `update` 逐个加入。没有规则就不增加来源；四个字母都找到，可以提前结束分界点枚举。

我逐行确认了 `zip`、`setdefault` 和 `update` 的行为。需要保留的是所有合法来源，不能遇到一条新规则就丢掉旧来源。四种字母是常数，时间为 $O(m^3)$，空间为 $O(m^2)$，最后按 `WING` 顺序输出整个名字的来源。

## P10236 排卡：一个最大值会丢掉连接处的信息

每次从双端队列的一端取数，按取出的顺序计算相邻两数的幂得分。我先看了这段先取左端、先取右端两个状态，随后追问能不能合并成一个区间最大值，以及能不能记录最后取出的数字。

只保留最大值不够。先取走一个 `2`，剩下 `[2,5]`：内部按 `2→5` 得 32，按 `5→2` 得 25。但接上前面的 `2` 后，两种总分变成 36 和 57。内部更优的方案，连接时反而更差，所以连接处的数必须留在状态里。

我最后选了剩余区间的定义，并要求直接使用三维数组：

- `dp[l][r][0]`：还剩 `[l,r]`，上一次取出左侧的 `arr[l-1]`，后面最多还能增加多少分。
- `dp[l][r][1]`：还剩 `[l,r]`，上一次取出右侧的 `arr[r+1]`，后面最多还能增加多少分。

这里的 0、1 只描述上一次的来源，接下来仍能自由选左或右。前一个数只可能是剩余区间外紧邻的两个位置，不必按数值范围再开一维。

```python
if l > 0:
    # 上一个数是 arr[l-1]，现在选择取 arr[l] 或 arr[r]
    dp[l][r][0] = max(
        forward[l - 1] + dp[l + 1][r][0],
        score(arr[l - 1], arr[r]) + dp[l][r - 1][1]
    )

if r < n - 1:
    # 上一个数是 arr[r+1]，现在选择取 arr[l] 或 arr[r]
    dp[l][r][1] = max(
        score(arr[r + 1], arr[l]) + dp[l + 1][r][0],
        backward[r] + dp[l][r - 1][1]
    )
```

取左端后，剩余区间变成 `[l+1,r]`，刚取出的数从左边来，进入第 0 类；取右端后则进入 `[l,r-1]` 的第 1 类。`forward`、`backward` 预先保存相邻位置的有向得分，跨越区间的得分现场计算。只剩一个数时，还要算它与前一个数的连接分，因此基础状态不是全部为 0。

整题入口按定义应比较 `dp[1][n-1][0]` 和 `dp[0][n-2][1]`，第一次取数不产生相邻得分。当前源码扫描所有状态取最大值：每一项得分非负，每个有效剩余状态又都能前接一段合法历史，因此也能得到整题答案。直接写两个入口更容易对应状态含义。

每个数对的得分取模，总分不取模，`0^0` 单独按 0 处理。计入快速幂后，时间为 $O(n^2\log MOD)$，空间为 $O(n^2)$。这次对话里的剩余区间转移通过了两个样例、200 组随机穷举对拍，并逐项核对了 4992 个有效状态；改成完整三维数组后，也检查了 `n=1000` 的输入。
