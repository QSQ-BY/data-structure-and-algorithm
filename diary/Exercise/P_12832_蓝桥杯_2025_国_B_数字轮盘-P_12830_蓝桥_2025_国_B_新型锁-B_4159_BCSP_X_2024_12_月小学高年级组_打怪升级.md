## P12832 数字轮盘：两次局部翻转拼成固定步长为 2 的旋转

第一阶段顺时针转 $K$ 次，相当于整体循环移位了 $k = K \bmod N$ 步。第二阶段每次操作分两步：先翻转从指针开始的顺时针前 $N-1$ 个数，再翻转除指针外的 $N-1$ 个数。如果盯着单步看，环上的相对顺序一正一反；但把两步连起来手算几个小例子就会发现，两次翻转把环的相对朝向又翻了回来，净效果只是把轮盘朝恢复方向推进了 2 格。

```python
for _ in range(t):
    n,k = read()
    k = k%n
    if(k == 0):
        print(0)
        continue
    if(n%2 == k%2):
        ans = ((n - k)//2)
    else:
        if(k%2 == 0):
            ans = (n*2 - k)//2
        else:
            ans = -1
    print(ans)
```

这样整道题就变成了：需要再转 $N - k$ 格（或者多绕一圈转 $2N - k$ 格）回到原位，而每次操作固定推进 2 格。

- 当 $N$ 和 $k$ 奇偶性相同时，$N - k$ 是偶数，直接走 $(N - k) / 2$ 次就能复原；
- 当 $N$ 和 $k$ 一奇一偶时，第一圈剩下的 $N - k$ 是奇数，一步跨不过去。如果 $k$ 是偶数（此时 $N$ 必为奇数），多绕一圈后的 $2N - k$ 会变成偶数，还能用 $(2N - k) / 2$ 次救回来；如果 $k$ 是奇数（此时 $N$ 为偶数），无论绕多少圈距离都是奇数，永远无法复原，输出 `-1`。

单组数据只做奇偶判断，时间复杂度 $O(1)$。

## P12830 新型锁：把相邻 LCM 约束拆到质因数的指数上

序列长度为 2025，要求任意相邻两项满足 $\operatorname{lcm}(a_i, a_{i+1}) = 2025$。把 $2025$ 分解质因数得到 $2025 = 3^4 \times 5^2$，因此序列里的每个数都只能含有质因子 $3$ 和 $5$，对应指数分别在 $[0, 4]$ 和 $[0, 2]$ 之间。两个数的 $\operatorname{lcm}$ 等于 $2025$，等价于它们在 $3$ 上的指数最大值为 $4$，且在 $5$ 上的指数最大值为 $2$。

```python
for i in range(2,n+1):
    for j in range(limit1+1):
        for k in range(limit2+1):
            for x in range(limit1+1):
                for y in range(limit2+1):
                    if(max(x,j) == limit1 and max(y,k) == limit2):
                        dp[i][j][k] = (dp[i][j][k] + dp[i-1][x][y])%mod
ans = sum(sum(row)for row in dp[n])%mod
print(ans)
```

`dp[i][j][k]` 表示填完前 $i$ 个位置、且第 $i$ 个数是 $3^j 5^k$ 时的方案数。每个位置只有 $(4+1) \times (2+1) = 15$ 种取值，状态非常小，直接枚举上一位的指数 $(x, y)$ 和当前位的指数 $(j, k)$，只要满足 $\max(x, j) = 4$ 且 $\max(y, k) = 2$ 就累加转移。因为是填空题，$2025 \times 15 \times 15$ 的计算量瞬间就能跑出结果。

## B4159 打怪升级：倒序维护存活血量的后缀最大值，消掉内层转移循环

主角有血量和等级两个属性，但关卡数 $n \le 1500$，如果把血量塞进状态下标肯定存不下。好在等级最高只能升到 $n+1$，所以我把状态反过来设成 `dp[i][j]`：打完第 $i$ 关并使用经验书后，主角处于等级 $j$ 时能保住的最大血量（0 表示不可达）。

在 `solution1()` 里，我先对上一关的每个可达等级 `pre` 扣掉 Boss 伤害 `blood = dp[p][pre] - g[i-1][pre-1]`，如果存活（`blood > 0`），再用内层循环去更新第 $i$ 关的 `j in range(1, pre + 2)`。这样写每关要跑两重循环，总复杂度是 $O(n^3)$，只能过前两个子任务。

仔细看“改变等级”这一支转移：只要上一关打完 Boss 后活下来了，原等级 `pre` 可以变成 $[1, \text{pre} + 1]$ 里的任意等级 $j$。反过来站在目标等级 $j$ 的角度看，所有满足 $\text{pre} \ge j - 1$ 的原等级都能不回血直接转成 $j$。于是在 `solution2()` 里，我改成按目标等级 $j$ 从 $i+1$ 倒序往 $1$ 扫，用 `best` 顺手维护后缀最大存活血量：

```python
    for i in range(1, n + 1):
        # 改成等级 j，要求原等级 pre >= j - 1
        # 倒序枚举 j，维护这些原等级打完 Boss 后剩余血量的后缀最大值
        best = 0
        for j in range(i + 1, 0, -1):
            if j > 1:
                pre = j - 1
                blood = dp[i - 1][pre] - g[i - 1][pre - 1]
                # best 初始为 0，只有存活状态（blood > 0）能更新它
                best = max(best, blood)

            # 选择改变等级，不回血
            dp[i][j] = best

            # 选择回血，原等级和目标等级都必须为 j
            if j <= i:
                blood = dp[i - 1][j] - g[i - 1][j - 1]
                # 必须先活着打完 Boss，才能使用经验书回血
                if blood > 0:
                    dp[i][j] = max(dp[i][j], blood + arr[i - 1])
```

这里有两个必须卡死的存活条件：一是更新 `best` 时，因为 `best` 初值为 0，只有 `blood > 0` 的存活状态才能进入后缀最大值；二是选择回血分支时，也必须先保证打完 Boss 后的 `blood > 0`，不能先死了再用经验书把血加回正数。把内层循环压成后缀最大值后，时间和空间复杂度都降到了 $O(n^2)$，顺利跑满 $n \le 1500$。
