## P16818 仓库管理：固定每个货架的容量上限

这题要最小化单个货架上的最大箱数。我先固定上限 `k`，判断能否放完箱子，并让总耗电量落在 `[L,R]` 内。上限放宽后，原来可行的分配仍然可行，因此可以二分第一个可行的 `k`。实现时我要求把 `check` 单独写成普通函数，便于看清判定条件。

固定 `k` 后，把箱子尽量放在编号小的货架上，得到最低耗电量。设 `q=N//k`、`t=N%k`，前 `q` 个货架放满，剩下 `t` 个放在下一层：

```cpp
bool check(ll k) {
    if (m * k < n) return false;

    ll q = n / k;
    ll t = n % k;

    ll minCost = k * q * (q + 1) / 2 + t * (q + 1);
    ll maxCost = (m + 1) * n - minCost;

    return minCost <= r && maxCost >= l;
}
```

先检查总容量，接着用等差数列求和算出 `minCost`。把货架编号左右镜像，总耗电量变成 `(M+1)*N-minCost`，就得到了 `maxCost`。

这份判定还依赖耗电量没有整数空缺：把一个箱子移到相邻的下一层，耗电量只增加 1；只要还不是最靠右的满载安排，就能找到这样的移动。因此只需判断两个区间是否相交。每次判定为 $O(1)$，二分总时间为 $O(log N)$。

## P1314 聪明的质监员：二分分界，再比较两侧

重量阈值 `W` 越大，留下的矿石越少，每个区间里的合格数量和价值总和都不增加，所以总检验值 `Y(W)` 单调不增。目标虽然是最小化绝对差，但绝对差本身不作为二分条件。

我用两条前缀和分别保存合格数量、合格价值。一次计算总检验值需要 $O(n+m)$，再找第一个满足 `Y(W)<=s` 的位置：

```cpp
while(left<right){
    int mid = left + (right-left)/2;
    if(calculate(mid)<=s){
        right = mid;
    }else{
        left = mid+1;
    }
}
// 最优值在分界点两侧；若 left 已是最小重量，left-1 仍是全选。
__int128 answer = s-calculate(left);
__int128 difference = calculate(left-1)-s;
if(difference<0) difference = -difference;
answer = min(answer,difference);
```

分界点这一侧的检验值已经不超过标准，前一个阈值仍可能更接近标准，所以最终比较两侧的差。源码把所有矿石都不选的阈值也纳入范围，并用 `__int128` 保存检验值总和，避免单个区间能存下、总和却溢出的情况。总时间为 $O((n+m)log W_{max})$。

## P1462 通往奥格瑞玛的道路：最短路负责判断血量够不够

我追问过：血量明明还有盈余，为什么一定要沿最短路线走，能不能多耗一点血来避开高收费城市？这里需要分开看两个量。

外层二分允许经过的城市收费上限 `limit`，高于上限的城市已经被过滤掉。内层最短路计算这些城市组成的子图中，最少需要损失多少血量。它只判断是否存在一条耗血不超过 `b` 的路线，并没有要求最终选择全图中耗血最少的路。

当前实现用 `set<pair<距离,城市>>` 取出累计耗血最少的状态，扩展时继续检查城市收费：

```cpp
for (auto [v,c] : g[u]){
    if(f[v] > limit){
        continue;
    }
    if(d+c < dist[v]){
        dist[v] = d+c;
        q.insert({dist[v],v});
    }
}
```

子图中的最小耗血如果仍超过 `b`，其他路线只会更费血；如果不超过 `b`，这个收费上限就可行。提高 `limit` 只会增加允许经过的城市，判定因此具有单调性。当前写法总时间可记为 $O((n+m)log nlog F_{max})$。
