# 排名的拓扑方向，与迷宫里的额外状态

## P5754 排名：按编号比较答案，决定拓扑的方向

[源码](../../Exercise/graph_theory/P_5754_JSOI_2010_排名.py)

题目要比较的是按学生编号排列的名次数组。我需要先分清它和拓扑出队顺序的区别：编号较小的学生，其最终名次的优先级更高。

 求字典序最小的名次数组时，源码从低分者指向高分者，从第 n 名倒着分配。当前能放在末尾的人中，优先处理编号最大的，把靠前的编号留给更好的名次。求字典序最大时反转边，从第 1 名往后分配，同样优先取编号最大的候选。

 两次排序都会消耗入度，因此第二次要重新建图和统计入度。堆负责选择当前编号最大的可选节点，总时间为 O(n log n)，图和堆占 O(n) 空间。这道题要先说清“输出数组按什么比较”，再决定边和分配名次的方向。

## P8673 迷宫与陷阱：同一个位置还要比较剩余无敌时间

[源码](../../Exercise/backtrack_algorithm&search/P_8673_蓝桥杯_2018_国_C_迷宫与陷阱.py)

走到同一个格子，手里的无敌时间不同，之后能走的路也不同。只用一个布尔 visited 会把还有价值的状态一起排除。

 当前代码用 BFS 保证步数递增，s[x][y] 记录已经到达该格子时最大的剩余无敌时间。下面是陷阱判定和状态筛选，省略了边界、墙壁判断以及后续入队。

```python
#广度优先搜索的顺序天然保证了步数的递增
        # 进入陷阱前必须还有无敌时间
        if cell == "X" and t == 0:
            continue

        # 计算到达新位置后的剩余时间
        if cell == "%":
            nt = k
        else:
            nt = max(t - 1, 0)

        # 以前已经不晚于这次到达，且剩余无敌时间不少
        if nt <= s[nx][ny]:
            continue
        s[nx][ny] = nt
```

进入陷阱时先检查当前的 t，再计算走完这一步后的 nt；遇到道具则把时间重置为 k。如果此前已经不晚于本次到达，而且剩余时间不少于 nt，本次状态就没有继续扩展的必要。

 这里保留的是一种支配关系。较晚到达但无敌时间更多的状态仍可能有用，不能因为格子出现过就直接丢掉。按每格最多保留 k+1 次严格改善估计，时间和队列空间的保守上界都是 O(n²k)。

## P9425 AB 路线：位置相同，当前这一段的进度也可能不同

[源码](../../Exercise/backtrack_algorithm&search/P_9425_蓝桥杯_2023_国_B_AB_路线.py)

AB 路线要求连续走满 k 个相同字母后切换。到达坐标时，还需要知道当前已经走到这一段的第几个字母。格子本身确定字母，所以 visited 只需额外区分进度 t。

 我在源码里用整数的不同二进制位标记这些进度。摘出决定下一状态和判重的部分：

```python
next_step = step + 1
# 到达下一格后，是这一段的第几个字母
nt = t + 1 if t < k else 1
bit = 1 << nt
#当前这一位是1，说明这个状态已经重复了
if vis[nx][ny] & bit:
    continue
vis[nx][ny] |= bit
```

第 t 位为 1，表示这个坐标、这个段内进度已经访问过。它和“格子是否访问过”是两种不同的信息。状态规模是 O(nmk)，每个状态只有四个方向的转移；位掩码压缩了 visited 的表示，但没有减少需要考虑的逻辑状态数。

## P3956 棋盘：最少步数和最少花费需要不同的出队顺序

[源码](../../Exercise/backtrack_algorithm&search/P_3956_NOIP_2017_普及组_棋盘.py)

棋盘里的移动费用可能是 0、1 或 2。普通 BFS 按步数处理，第一次走到终点时不一定最便宜，因此这里用小顶堆按累计花费做 Dijkstra。

 状态记录坐标和当前颜色。能否连续施法，可以直接由当前位置是不是原本无色来判断。下面保留费用计算和更新条件，省略边界判断与入堆。

```python
if g[nx][ny] == 2:
    # 当前也是临时染色格，不能连续施法
    if g[x][y] == 2:
        continue
    next_color = color
    next_cost = cur_cost + 2
else:
    next_color = g[nx][ny]
    next_cost = cur_cost + (next_color != color)

# 只有找到更便宜的方案才更新、入堆
if next_cost < cost[nx][ny][next_color]:
    cost[nx][ny][next_color] = next_cost
```

进入无色格要花 2，并沿用当前颜色；如果自己已经站在临时染色格上，就不能再次施法。进入有色格时只比较颜色是否改变。堆中还要跳过已经被更低费用替代的旧记录。

 两种颜色使状态数仍为 O(m²)，每个状态的出边数为常数，总时间为 O(m² log(m²))，空间为 O(m²)。状态表示解决“后面能做什么”，优先队列解决“先扩展谁”。
