# P1309 瑞士轮：把逐个插入改成有序归并

2026-10-15

[源码](../../Exercise/Ad-hoc/P_1309_NOIP_2011_普及组_瑞士轮.py)

这次我练习了瑞士轮的排名维护。共有 $2N$ 名选手，每轮按当前排名相邻配对，实力较高的人获胜并加一分。比赛结束后重新确定排名，再进入下一轮。

我先沿着“谁加分，就把谁向前移动”的思路写，修正比较规则后，又尝试用 `bisect_left` 定位。最后改成把胜者、败者分别收集，再归并出下一轮的排名。

## 排名要同时比较分数和编号

我用 `scores` 保存分数，`arr` 保存实力，`order` 保存按排名排列的选手下标。分数和实力都通过选手下标访问，移动排名时只移动 `order` 中的元素。

这里需要一直保持同一种比较规则：分数高的在前，同分时编号小的在前。用排序键表示就是 `(-scores[x], x)`。代码中的下标从零开始，不影响编号之间的大小关系。

例如，1 号原来比 2 号少一分，获胜后两人同分，1 号就应排到前面。所以加分后的前移判断、二分查找的位置以及最终归并的选择，都要包含编号这一项。

当前初始排序只用了 `-scores[x]`，它仍然满足规则：`order` 一开始按编号递增，而 Python 的排序是稳定的，同分的人会保留原来的编号顺序。

## 二分查找之后，还有列表搬移

最初的写法是胜者加分后，和前面的选手逐个比较、交换。在分数比较接近时，一个胜者可能跨过很多败者，单轮最坏需要 $O(N^2)$ 次操作。

我随后用 `bisect_left` 在胜者前面的有序区间里查找新位置。因为胜者只加分，排名只可能前移；查找时按负分数和编号组成的键比较，就能同时处理分数和同分顺序。

这一步把位置查找降到了 $O(\log N)$，但随后还要执行 `pop` 和 `insert`。Python 列表中的元素需要搬移，单次更新最坏仍是 $O(N)$，因此整轮最坏还是 $O(N^2)$。

例如所有人初始同分，每对中排在前面的人获胜，后面的胜者会依次跨过前面的败者。逐个维护排名时，单轮搬移量就可能累积到 $0+1+\cdots+(N-1)$。我需要减少这些重复搬移。

## 按胜负分组，保留各组的相对顺序

归并写法利用了每轮分数变化的规律：胜者统一加一分，败者分数不变。我按本轮开始时的 `order` 依次比赛，把两类选手分别收集。下面摘录分组部分，省略函数声明和后续归并：

```python
winners = []
losers = []
for i in range(0,2*n,2):
    a = order[i]
    b = order[i+1]
    if arr[a] > arr[b]:
        winner, loser = a, b
    else:
        winner, loser = b, a
    scores[winner] += 1
    winners.append(winner)
    losers.append(loser)
```

`a`、`b` 是选手下标，比较实力时访问 `arr[a]` 和 `arr[b]`。比赛期间只更新分数、追加分组，保留原来的 `order`，这样所有对阵都取自本轮开始前的排名。

`winners` 是原排名中的一个子序列。任意两个胜者都加一分，分数差不变；原来同分的胜者，加分后仍然同分，编号顺序也不变。因此胜者组仍然按完整的排名规则有序。败者组同样是有序子序列，而且分数没有变化，也保持有序。

这样，每轮比赛后就得到了两个可以直接归并的列表。

## 用两个指针生成新排名

两个列表各有 $N$ 人。我用 `i` 指向当前胜者，`j` 指向当前败者，每次选排名更靠前的人放入 `merged`：

```python
merged = []
i = j = 0
while i < n and j < n:
    a = winners[i]
    b = losers[j]
    if scores[a] > scores[b] or (scores[a] == scores[b] and a < b):
        merged.append(a)
        i += 1
    else:
        merged.append(b)
        j += 1
merged.extend(winners[i:])
merged.extend(losers[j:])
order = merged
```

每次选出一人，只推进对应组的指针。某一组取完以后，另一组剩下的人已经有序，直接接到末尾即可。最后用 `merged` 替换 `order`，下一轮就能继续按相邻位置配对。

每轮分组、归并都只需线性遍历，时间为 $O(N)$；加上最初的一次排序，总时间为 $O(N\log N+RN)$，额外空间为 $O(N)$。

这次归并实现通过了样例、5832 个小规模穷举用例和 3000 组随机对拍，对拍时比较了完整排名、每人的分数和最终输出。还运行了 $N=10^5$、$R=50$ 的全员初始同分测试，本机耗时约 2.69 秒，并检查了最终排名、总得分和选手是否重复或遗漏。

这道题里可以复用的是“同类更新保留相对顺序”这个条件。以后遇到每轮批量修改排名的题，我会先看看不同组内部是否还保持有序，再决定怎样维护整个序列。
