这篇根据当前源码补记两道构造和贪心题。项链排列需要同时满足变化次数与字典序，乘积最大则要在绝对值之外处理符号、零和无法交换的情况。

## P12834 项链排列：先确定连续段，再分配多余字符

[源码](../../Exercise/greedy_algorithm/P_12834_蓝桥杯_2025_国_B_项链排列.py)

虽然题名叫项链，这道题计算的是字符串中相邻字符的变化，首尾不相邻。若变化次数为 `C`，字符串就有 `C+1` 个非空连续段，段的字符在 `L`、`Q` 之间交替。

`C=0` 时只能使用一种字符。一般情况下，若 `A=B`，最多产生 `2A-1` 次变化；否则最多产生 `2*min(A,B)` 次变化。这一步只负责排除不可能的情况，后面还要决定每段的长度。

`C` 为奇数时，起点和终点不同，两种字符所需的段数相等。因为 `L<Q`，优先从 `L` 开始。`C=2t` 为正偶数时，两端相同；若从 `L` 开始，需要 `t+1` 个 L 段、`t` 个 Q 段。如果 L 恰好只有 `t` 个，就只能从 Q 开始并以 Q 结束。

当前代码建立交替骨架的部分如下：

```python
#变化次数为偶数，那么一定是aba类型的
if(trans % 2 == 0):
    cnt = trans//2
    if a == cnt:
        ans = ["Q","L"]*cnt
        a_remain = 0
    else:
        ans = ["L","Q"]*cnt
        a_remain = a - cnt - 1
    b_remain = b - cnt
elif(trans%2 == 1):
    cnt = (trans+1)//2
    ans = ["L","Q"]*cnt
    a_remain = a - cnt
    b_remain = b - cnt
```

后续把多余的 L 放到开头，把多余的 Q 放到最后一个 Q 段。偶数次变化且从 L 开始时，再补上预留的结尾 L。这样不增加新的段，也不改变变化次数。

字典序的理由是：额外的 L 应尽量靠前，推迟第一个 Q 的出现；额外的 Q 应尽量靠后，让前面的 Q 段尽早结束，早点遇到下一个 L。例如 `A=B=2,C=2`，最小结果是 `LQQL`。若强行排成 `LLQQ`，字典序虽然更小，却只有一次变化。

构造和输出的时间为 `O(A+B)`，当前列表实现占用 `O(A+B)` 空间。补记时枚举了总长度 1 到 8 的所有 L/Q 字符串，以每组数量和变化次数对应的最小字符串作参照，共 284 个输入用例通过。

## P8669 乘积最大：绝对值选完以后，还要决定符号

[源码](../../Exercise/greedy_algorithm/P_8669_蓝桥杯_2018_省_B_乘积最大.py)

当前实现把每个数存成 `(绝对值, 符号)`，按绝对值从大到小排序，先选前 `k` 个。这一步保证乘积的绝对值最大，但负数个数为奇数时，数值未必最大。

若能够把负积变成正积，只需要考虑两种交换：从已选中拿走绝对值最小的负数，换入未选中绝对值最大的正数；或者拿走已选中绝对值最小的正数，换入未选中绝对值最大的负数。

设第一种交换的比率为 `remaining_positive / selected_negative`，第二种为 `remaining_negative / selected_positive`。比较哪一种损失更小，可以交叉相乘，不需要浮点除法：

```python
    swap_negative = selected_negative is not None and remaining_positive is not None
    swap_positive = selected_positive is not None and remaining_negative is not None

    if swap_negative and (not swap_positive or remaining_positive * selected_positive >= remaining_negative * selected_negative):
        ans.remove((selected_negative,1))
        ans.append((remaining_positive,0))
        is_negative = False
    elif swap_positive:
        ans.remove((selected_positive,0))
        ans.append((remaining_negative,1))
        is_negative = False
```

为什么一次交换就值得单独考虑？最初选出的数绝对值都不小于未选中的数，每替换一个数，绝对值乘积都不会增大。任何把奇数个负数改成偶数个负数的方案，都至少包含一次异号替换；挑出其中的一次，已经能改变符号，额外替换只会继续损失绝对值。因此可以只比较最划算的单次异号交换。

两种交换都不存在时，分支才转向其他结果：

- 有零就可以得到 0，优于负积。
- `k==n` 时没有选择余地，保留全部数，即使其中有正数也不能换成别的子集。
- `k<n` 且无零时，这种无法异号交换的情况意味着所有数都为负且 `k` 为奇数，要取绝对值最小的 `k` 个，让负积最接近零。

还需要处理题目定义的负数余数。Python 的负数 `% MOD` 通常给出非负结果，本题却要求保留负号。源码先计算绝对值乘积的模，再根据最终符号输出：

```python
result = 1
for number,_ in ans:
    result = result * number % MOD
print(-result if is_negative else result)
```

比较交换方案时使用原始绝对值，不能先取模再比较大小。总时间为 `O(n log n)`，空间为 `O(n)`。补记时随机生成 250 组不超过九个数的输入，包含正数、负数和零，枚举所有大小为 `k` 的子集核对，当前实现通过了这些用例。
