## P12381 保险箱：按位传递 `-1 / 0 / +1` 三种进退位状态

把 $n$ 位数字 $x$ 变成 $y$，每一位加 1 到 10 会向高位进 1，减 1 到 -1 会向高位退 1。单看某一位，既可以直接从 $x_i$ 走到 $y_i$，也可以绕过 0 或 9 产生一次借位或进位。因为单步调整跨度不会超过 10，当前位向高位传递的影响只有 `-1`（退位）、`0`（无进退位）、`+1`（进位）三种可能：

```python
# 从右往左处理
for i in range(1, n + 1):
    cur = i%2
    pre = 1 - cur
    x = a[n - i] - 48
    y = b[n - i] - 48
    dp[cur] = [INF] * 3
    # 枚举上一位传来的进位
    for c in (-1, 0, 1):
        # 枚举当前位向高位产生的进位
        for k in (-1, 0, 1):
            cost = abs(y + 10 * k - x - c)
            dp[cur][k + 1] = min(
                dp[cur][k + 1],
                dp[pre][c + 1] + cost
            )
```

从低位往高位推，当前位原本是 $x$，加上低位传上来的进退位 $c \in \{-1, 0, 1\}$ 后变成 $x + c$。如果希望这一位最终停在 $y$，并且向更高位产生 $k \in \{-1, 0, 1\}$ 的进退位，那么当前位实际需要走到的目标值就是 $y + 10k$，所需操作次数为 $|y + 10k - x - c|$。用下标 `c + 1` 和 `k + 1` 把 `-1, 0, 1` 映射到 `0, 1, 2`，每一步只做 $3 \times 3$ 的常数转移，时间复杂度 $O(n)$。

## P12327 蜗牛：把每根竹竿拆成“底部”与“传送门出口”两个状态

蜗牛要从第 1 根竹竿底部走到第 $n$ 根竹竿底部，既可以沿着地面走（速度 1），也可以顺着竹竿往上爬（速度 0.7）或往下滑（速度 1.3），通过竹竿上的传送门瞬移到下一根竹竿的 $b_i$ 高度处。

处理第 $i$ 根竹竿时，真正需要区分的只有两个位置：到达第 $i$ 根竹竿底部的最短时间 `dp[i][0]`，以及刚从第 $i-1$ 根竹竿传送到第 $i$ 根竹竿高度 $b_i$ 处的最短时间 `dp[i][1]`：

```python
for i in range(2, n + 1):
    # 上一根竹竿的传送门出口到入口的爬行时间
    if a[i - 1] >= b[i - 1]:
        t = (a[i - 1] - b[i - 1]) / 0.7
    else:
        t = (b[i - 1] - a[i - 1]) / 1.3

    # 通过传送门到达第 i 根竹竿
    dp[i][1] = min(
        dp[i - 1][0] + a[i - 1] / 0.7,
        dp[i - 1][1] + t
    )

    # 到达第 i 根竹竿底部
    dp[i][0] = min(
        dp[i - 1][0] + x[i] - x[i - 1],
        dp[i][1] + b[i] / 1.3
    )
```

要走传送门到第 $i$ 根竹竿，必须先爬到第 $i-1$ 根竹竿高度为 $a_{i-1}$ 的入口：如果之前在第 $i-1$ 根竹竿底部，就要往上爬 $a_{i-1} / 0.7$；如果之前已经在第 $i-1$ 根竹竿的传送门出口 $b_{i-1}$ 处，就只需要在竹竿上补一段 $|a_{i-1} - b_{i-1}|$ 的高度差（向上除以 0.7，向下除以 1.3）。算出 `dp[i][1]` 后，再用它加上从 $b_i$ 滑回地面的 $b_i / 1.3$，与直接从上一根竹竿底部走地面过来的时间取最小值，就能得到 `dp[i][0]`。

## AT_abc483_c Second Choice Election：只扫描选票发生变化的第二志愿候选人

每张选票有第一志愿 $a$ 和第二志愿 $b$。依次假设每个候选人 $k = 1 \dots n$ 退选，原本投给 $k$ 的选票会全部转给各自的第二志愿，求每次退选后的获胜者。

如果每次退选都重新扫一遍所有候选人，复杂度会退化到 $O(n^2)$。其实当候选人 $k$ 退选时，没有收到 $k$ 的转移票的人票数根本没变。在不考虑转移票的情况下，未退选的人里票数最高的要么是全局第一名 `best1`，要么（当 `k == best1` 时）是全局第二名 `best2`：

```python
for k in range(1, n + 1):
    # 排除已经退出的候选人
    winner = best2 if k == best1 else best1
    mx = cnt[winner]

    # 统计从 k 转移出去的选票
    changed = []

    for b in groups[k]:
        if add[b] == 0:
            changed.append(b)
        add[b] += 1

    # 只检查票数发生变化的候选人
    for b in changed:
        votes = cnt[b] + add[b]

        if votes > mx or (votes == mx and b < winner):
            mx = votes
            winner = b

        # 清空临时票数，供下一轮使用
        add[b] = 0
```

因此每一轮先把基准擂主设为 `best1` 或 `best2`，然后只遍历 `groups[k]` 把转移票累加到临时数组 `add` 中，并用 `changed` 列表记录本轮票数真正增加了的候选人。比完这批人之后立刻把 `add[b]` 清零。因为每张选票只属于一个 `groups[k]`，所有轮次里内层循环的总执行次数恰好等于总选票数 $m$，总时间复杂度 $O(n + m)$。

## AT_abc483_d Glitchy_Robot：把单点翻转转化为后缀前缀和的整体平移

机器人按序列 $a_1, \dots, a_n$ 在数轴上移动，经过的所有整数点构成的区间长度等于最大位置与最小位置之差加 1，即 $\max(s) - \min(s) + 1$，其中 $s$ 是前缀和数组。

如果把第 $i$ 步的位移从 $a_i$ 翻成 $-a_i$，那么翻转位置之前的坐标 $s_0 \dots s_{i-1}$ 完全不变，而从 $s_i$ 开始往后的所有前缀和都会整体加上同一个偏移量 $d = -2 a_i$：

```python
for i in range(1, n + 1):
    # 翻转第 i 个元素
    d = -2 * a[i - 1]

    r = max(pre_max, suf_max[i] + d)
    l = min(pre_min, suf_min[i] + d)

    ans = max(ans, r - l + 1)

    # 更新前缀最值
    pre_max = max(pre_max, s[i])
    pre_min = min(pre_min, s[i])
```

整段后缀平移 $d$ 之后，新的后缀最大值就是原后缀最大值 `suf_max[i] + d`，新的后缀最小值就是 `suf_min[i] + d`。预处理出后缀最值数组后，从左到右扫描翻转位置 $i$，一边维护前半段的 `pre_max` 和 `pre_min`，一边在 $O(1)$ 时间内合并前后两段的极值，总时间复杂度 $O(n)$。

## P8656 对局匹配：按公差 $k$ 拆成互不干扰的链做打家劫舍 DP

选出尽量多的人，使得任意两人的积分差不等于 $k$。

- 当 $k = 0$ 时，同分的人最多只能选 1 个，答案直接是不同积分的种类数 `len(cnt)`。
- 当 $k > 0$ 时，积分 $x$ 只会和 $x - k$、$x + k$ 冲突。把所有出现过的积分按公差 $k$ 串成若干条连续的链，不同链之间没有任何冲突，每条链内部就变成了经典的“相邻不能同时选”的最大权独立集问题：

```python
    for row in g:
        dp = [0] * (len(row) + 1)

        for i in range(1, len(row) + 1):
            dp[i] = max(
                dp[i-1],
                dp[i-2] + cnt[row[i-1]] if i >= 2 else cnt[row[i-1]]
            )

        ans += dp[-1]
```

这里有一个细节：我在代码里只把 `cnt` 中实际存在的积分并且相差恰好为 $k$ 的相邻项塞进同一条链 `row`（`while x in cnt`）。如果某个模 $k$ 同余类在中间断开了（比如有 $x$ 和 $x + 2k$，但没有 $x + k$），它们会自然断成两条独立的链分别做 DP，不仅不用给整条值域补 0，而且只遍历实际出现过的元素，时间和空间复杂度都只和不同分数的个数成正比。
