# 从排列组合到连通块：三道练习里的状态与边界

今天先后写了 P1706 全排列、P1157 组合输出和 P1683 入门。前两题都用 DFS 枚举答案，区别在于“下一步还能选什么”；P1683 处理的是网格连通性，我分别用并查集和 DFS 写了一遍。

## P1706 全排列：用位掩码保存可选数字

全排列的每一层都要从尚未使用的数字中选择一个。代码没有单独维护 `visited` 数组，而是用 `state` 的每一位表示对应数字是否还可用：

```python
def dfs(pos:int,state:int):
    global arr
    if(pos == n):
        print_an_answer(arr)
        return
    temp = state
    while(temp != 0):
        bit = (-temp &temp)
        new_number = bit.bit_length()
        arr[pos] = new_number
        next_state = state^bit
        dfs(pos+1,next_state)
        arr[pos] = 0
        temp -= (-temp & temp)
```

`-temp & temp` 取出最低位的 `1`，`bit_length()` 再把这一位换算成数字。因为每次都从最低位开始取，可选数字天然按从小到大的顺序出现，最后得到的排列也是字典序。递归前用异或删掉当前数字，返回后继续处理 `temp` 中的下一位。

## P1157 组合输出：限制下一个数的最小值

组合不考虑顺序，因此没有必要像全排列一样记录所有数字的使用状态。只要保证下一层选择的数字严格大于当前数字，就不会产生重复组合。

```python
def dfs(pos:int,min:int):
    global arr
    if(pos == m):
        print_an_answer(arr)
        return
    for number in range(min,n+1):
        if(n - number +1 < m-pos ):
            break
        arr[pos] = number
        dfs(pos+1,number+1)
        arr[pos] = 0
```

这里的 `pos` 是即将填写的位置，`min` 是这一层允许选择的最小数字。条件 `n-number+1 < m-pos` 表示从 `number` 到 `n` 的候选数量已经填不满剩余位置，此时后面的数字更少，可以直接结束循环。

## P1683 入门：只搜索起点所在的连通块

地图中的 `.` 和 `@` 可以看成图上的结点，上下左右相邻的安全格子之间有边，答案就是 `@` 所在连通块的大小。并查集做法会扫描整张图，把所有安全格子之间的相邻关系合并；DFS 则只从 `@` 出发，访问实际能够到达的部分。

```python
def dfs(x:int,y:int)->int:
    if(x<0 or x>=n or y<0 or y>=m or g[x][y] == "#"):
        return 0
    #标记为已经被访问
    g[x][y] = "#"
    count = 1
    for (dx,dy) in directions:
        count += dfs(x+dx,y+dy)
    return count
```

进入格子后直接把它改成 `#`，它以后既不会再次计数，也不会在相邻格子之间来回递归，因此不需要额外的 `visited` 数组。若 `@` 所在连通块有 `K` 个格子，DFS 的时间为 `O(K)`；最坏情况下遍历整张图，也就是 `O(nm)`。
