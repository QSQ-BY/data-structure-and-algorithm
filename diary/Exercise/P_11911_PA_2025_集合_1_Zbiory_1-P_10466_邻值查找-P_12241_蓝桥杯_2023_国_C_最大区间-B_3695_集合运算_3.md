## P11911 集合 1：用一个整数表达一个集合

[源码](../../Exercise/simulation/P_11911_PA_2025_集合_1_Zbiory_1.py)

对话里我先问了具体题意和算法，后来又问能否不用 bytearray。当前版本把元素 y 映射到第 y-1 位，集合并、交就分别用按位或、按位与。

 新集合只引用编号更小的集合，因此按输入顺序构造即可：

```python
# 引用的集合编号总是更小，因此可以按输入顺序直接构造。
for i in range(n + 1, n + m + 1):
    operation = list(map(int, input().split()))
    op, x = operation[0], operation[1]
    if op == 1:
        state[i] = state[x] | state[operation[2]]
    elif op == 2:
        state[i] = state[x] & state[operation[2]]
    else:
        # 只翻转全集内的 n 位；直接用 ~ 会产生负数。
        state[i] = universe ^ state[x]
```

补集只在 1 到 n 的全集中取，所以用 universe^state[x]。Python 整数没有固定宽度，直接 ~x 会得到负数，不能直接作为这里的有限全集补集。

 查询只检查指定的一位。位集把逐元素操作交给大整数位运算完成，但它的成本仍随位数增长：一次并、交、补大致需要处理覆盖全集的机器字，不能把它们统统写成 O(1)。

## P10466 邻值查找：把在线插入转成倒序删除

[源码](../../Exercise/Ad-hoc/P_10466_邻值查找.py)

我先问过如何优化，也追问了堆和类似 C++ set 的结构。普通堆只能方便地取全局极值，无法直接查询任意值在有序集合里的前驱、后继。

 这道题可以离线处理：按数值排序后，用数组把相邻元素连接起来，再从原序列末尾倒着算。处理原下标 i 时，比它晚出现的元素都已经删除，链表里恰好剩下原下标 0 到 i 的元素。

```python
for i in range(n - 1, 0, -1):
    k = pos[i]#查找最后一个数字在排序后的顺序的链表的位置
    l, r = left[k], right[k]

    if l == -1:
        j = order[r]
    elif r == n:
        j = order[l]
    elif arr[i] - arr[order[l]] <= arr[order[r]] - arr[i]:
        # 等距离时选左邻居，因为左邻居数值更小
        j = order[l]
    else:
        j = order[r]

    answers[i] = (abs(arr[i] - arr[j]), j + 1)
```

有序集合中与当前值最近的元素一定在它左右两邻居里。距离相同时选数值更小的左邻居；算好答案后，把当前元素删除，使左右邻居直接连接。

 原来每次在前缀里扫描最坏为 O(n²)。现在排序 O(n log n)，每个元素的比较和删除 O(1)，总时间 O(n log n)，空间 O(n)。倒序处理让集合只需要删除，而数组链表正适合保存已经排好的邻接关系。

## P12241 最大区间：固定最小值，尽量向两侧延伸

[源码](../../Exercise/monotonic_queue&stack/P_12241_蓝桥杯_2023_国_C_最大区间.py)

区间得分为长度乘最小值。我固定 arr[i] 作为最小值，找到左右最近的严格更小元素，区间宽度就是 right[i]-left[i]-1。题目数值为正，在最小值不变时，应尽量扩展区间。

 两遍单调栈分别求左右边界，弹出条件都用 >=，让相等高度不会提前截断宽度。再枚举每个位置的 arr[i]·宽度即可。

 每个元素最多入栈、出栈一次，总时间 O(n)，辅助空间 O(n)。这道题与柱状图最大矩形的对应关系，来自“固定高度后寻找最大可延展宽度”。

## B3695 集合运算 3：移位要限制全集，计数可以按字节查表

[源码](../../Exercise/simulation/B_3695_集合运算_3.py)

整数位集还可以做整集合平移：左移后与 universe 做按位与，删除超过值域的元素；右移会自然丢弃小于 1 的元素。移位结果要写回对应集合，整数赋值不会通过另一个变量联动修改原值。

 我在对话里要求过自定义 bit_count，并确认 Python 3.8.6 的兼容性。当前代码预处理每种字节的二进制 1 的数量，然后按字节查表：

```python
# 预先统计每个字节中二进制 1 的个数。
_bit_counts = bytearray(256)
for i in range(1, 256):
    _bit_counts[i] = _bit_counts[i >> 1] + (i & 1)
_bit_counts = bytes(_bit_counts)

def bit_count(x):
    """返回整数绝对值的二进制表示中 1 的个数。"""
    x = abs(x)
    data = x.to_bytes((x.bit_length() + 7) // 8, 'little')
    return sum(data.translate(_bit_counts))
```

to_bytes 把整数拆成字节，translate 把每个字节替换为其 1 的个数，sum 再求总数。这个实现避免用 Python 循环逐位处理整个大整数。

 对话时指出，换掉 bit_count 后还要把 match/case 改成 if/elif，整份程序才能在 3.8.6 下解析；当前源码已采用 if/elif。运行环境兼容性要看整份文件使用的语法和方法，不能只验证替换的一个函数。
