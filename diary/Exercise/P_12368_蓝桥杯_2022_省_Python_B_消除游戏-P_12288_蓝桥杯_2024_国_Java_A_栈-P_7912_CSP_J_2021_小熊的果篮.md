# 消除游戏与两道数组链表模拟

## P12368 消除游戏：check 是下一轮需要重新判定的位置

[源码](../../Exercise/simulation/P_12368_蓝桥杯_2022_省_Python_B_消除游戏.py)

这题先讨论了如何保证模拟正确，之后又处理了三个点的 TLE。每轮重新扫描整个字符串，会反复检查邻居完全没变的位置，因此改成只跟踪受到本轮删除影响的候选。

 check 保存原字符串下标。第一轮用 set(range(n)) 检查全部位置；这一轮先根据旧邻接关系收集待删除集合 d，全部判断结束后才统一删除。下面摘出删除与收集下一轮候选的部分：

```python
for index in d:
    j, k = pre[index], nxt[index]

    if j != -1:
        nxt[j] = k
        next_check.add(j)

    pre[k] = j
    if k != n:
        next_check.add(k)
    available[index] = 1
check = next_check
```

只有前驱或后继改变的位置，下一轮的局部匹配条件才可能改变。我当时追问了 abb：若删除 a 和第一个 b，存活的第二个 b 的前驱改变，会被加入候选；它后面的节点仍接着这个 b，前驱并没有改变。如果第二个 b 也被其他匹配删除，处理它时又会把后继加入候选。

 所以这里不是“只看删除块某一个端点”，而是对 d 中每个删除位置都收集它当时的左右邻居。允许收集到随后也被删掉的位置，下一轮再跳过它们即可。第一轮 O(n)，之后每次删除只带来常数个候选，按集合操作平均 O(1) 估计，总时间和空间均为 O(n)。

## P12288 栈：把整段统计改成相邻边的局部贡献

[源码](../../Exercise/simulation/P_12288_蓝桥杯_2024_国_Java_A_栈.py)

这道题名叫栈，操作却包含删除中间已经出现的值，再把它放到末尾。值域固定时，可以用 pre、nxt 数组模拟双向链表，present 用 bytearray 记录是否存在；我也在对话里问了 bytearray 的含义。

 两个相邻数的和为奇数，等价于两者奇偶性不同，贡献可写成 (a^b)&1。删除已有的 x 时，只会拆掉 l-x、x-r 两条相邻关系，并在左右都存在时补上 l-r。

```python
# 删除已经存在的 x
if present[x]:
    l, r = pre[x], nxt[x]
    if l:
        #如果奇偶性不同就是1的贡献
        #奇偶性相同就是0的贡献
        ans -= (l ^ x) & 1
    if r:
        ans -= (x ^ r) & 1
    if l and r:
        ans += (l ^ r) & 1

    nxt[l] = r
    pre[r] = l
```

之后再把 x 接到尾部，只增加原尾部到 x 的一项贡献。0 号节点作为哨兵，pre[0] 保存尾节点，减少了空链和首尾情况的分支。

 每次操作只改常数个连接和贡献，总时间 O(n)，数组空间由值域上限决定。bytearray 的每个元素是一个字节，这里只使用 0、1，避免用普通 Python 整数列表保存存在标记。

## P7912 小熊的果篮：nxt 连接的是同一块中的水果

[源码](../../Exercise/simulation/P_7912_CSP_J_2021_小熊的果篮.py)

我问过 enumerate(arr,1) 为什么从 1 开始，也问过 nxt 到底存储什么关系。输出要求原水果编号，所以代码统一用 1 开始的编号，并且让 nxt 的下标与编号一致。

 每个同类连续块保存种类、头、尾和数量。一轮先从每个旧块取走最左端水果，再把剩余的相邻同类块合并。下面是合并部分，前面已经取走块头并用 nxt 找到了新块头：

```python
# 与左边剩下的块同类，合并
if next_cur and next_cur[-1][0] == fruit:
    last = next_cur[-1]

    # 左块的尾部接上右块的头部
    nxt[last[2]] = head
    # 更新合并后的尾部和数量
    last[2] = tail
    last[3] += count
else:
    next_cur.append([fruit, head, tail, count])
```

合并时，左块尾部接到右块头部。原编号之间可能有已取走的水果，所以 nxt[i] 不等于 i+1；它表示合并后同一块里，下一个仍存活水果的编号。

 还要区分本轮旧块和 next_cur：本轮删除导致的合并只能影响后续轮次，不能让合并后的块在本轮额外再取一次。每访问一个旧块就实际取走一个水果，因此跨所有轮次，块处理次数总和为 O(n)，整体时间和空间都是 O(n)。
