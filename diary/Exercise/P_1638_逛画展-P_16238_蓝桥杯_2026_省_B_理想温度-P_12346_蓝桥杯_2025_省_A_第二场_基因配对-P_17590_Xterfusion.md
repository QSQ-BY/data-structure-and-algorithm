## P1638 逛画展：满足覆盖后，左端继续收缩

[源码](../../Exercise/greedy_algorithm/P_1638_逛画展.py)

源码保留了二分长度和双指针两个版本。二分版检查是否存在长度为 L、包含全部画家作品的窗口，复杂度为 O(n log n)。双指针版则直接维护每个画家的频次和当前种类数。

 每加入一幅画，就删除窗口左端多余的同类作品；当 kinds==m 时，当前窗口已经覆盖所有画家，而且左端不能再删。只有长度严格变小时更新答案，也就保留了同长度时更靠左的方案。

 左右指针各前进至多 n 次，时间降为 O(n)，计数桶空间为 O(m)。窗口的合法性可以随着端点移动维护时，就值得检查外层二分是否还能省掉。

## P16238 理想温度：按补偿值分别维护最大净增量

[源码](../../Exercise/dynamic_programming/P_16238_蓝桥杯_2026_省_B_理想温度.py)

先计算 diff[i]=b[i]-a[i]。固定一个非零补偿值 x 后，区间里的 diff==x 会新增一个达标位置，diff==0 会损失一个原本达标的位置，其他差值不影响结果。这样就能把固定补偿值的问题转成最大子段和。

 逐个枚举补偿值并扫描全数组是 O(n²)。当前 test02 把各个 x 的状态同时保存在字典里，用累计零数量计算两次出现之间的损失：

```python
for x in diff:
    if x == 0:
        zeros += 1
        continue
    #- prev：补偿值选 x，且区间右端点固定在 x 最近一次出现的位置时，能获得的最大净增量。
    #- seen：处理到那个位置时，已经出现了多少个 0。
    # 首次出现时，默认状态也能让 cur 正确得到 1
    prev, seen = state.get(x, (0, 0))

    # 重新开始，或者接上上一次的最优区间
    #算出两次出现 x 之间有多少个零，也就是延伸区间需要付出的损失
    cur = max(1, prev - (zeros - seen) + 1)

    state[x] = (cur, zeros)
    gain = max(gain, cur)
```

state[x] 保存上一次以 x 结尾的最优净增量，以及当时已经经过的零数量。再次遇到 x 时，要么从这里重新开始，收益为 1；要么接在旧区间后，扣除中间新增的零再加 1。其他非零差值的贡献为 0，可以直接跨过。

 最后加回原本达标的零总数。字典操作按平均常数时间估计，总时间 O(n)，空间 O(n)。这里减少的是每种补偿值反复扫描中性位置的工作。

## P12346 基因配对：固定两个起点，长度可以一起统计

[源码](../../Exercise/dynamic_programming/P_12346_蓝桥杯_2025_省_A_第二场_基因配对.py)

这道题问两段等长、不相交、逐位相反的 01 子串有多少对。历史对话里，我专门问过这道题的做法。

 dp[i][j] 表示从 i、j 开始能连续匹配多少个相反字符。只要当前字符不同，就能接上右下角的状态。

```python
for i in range(n - 1, -1, -1):
    for j in range(i + 1, n):
        if s[i] != s[j]:
            dp[i][j] = dp[i + 1][j + 1] + 1
            ans += min(dp[i][j], j - i)
```

i 倒序枚举，使 dp[i+1][j+1] 在使用前已经算好。固定两个起点后，满足逐位相反的长度是 1 到 dp[i][j]；还要限制左段不能碰到右段，因此长度最多为 j-i。两者取最小值，就一次统计了这对起点的所有合法长度。

 这种写法把“枚举起点后逐个试长度”压成了 O(1) 转移，时间、空间均为 O(n²)。

## P17590 Xterfusion：固定步长后，从拼接点向两边计算

[源码](../../Exercise/dynamic_programming/P_17590_Xterfusion.py)

好的子序列前一部分步长为 2x，后一部分步长为 x。我先枚举 x，再让 prefix_dp[i] 记录以 i 结束、间隔为 2x 的连续 X 链，suffix_dp[i] 记录从 i 开始、间隔为 x 的连续 X 链。

 两个方向的递推如下，后续在每个拼接点计算 prefix_dp[i]+suffix_dp[i]-1：

```python
for i in range(n):
    if string[i] == "X":
        prefix_dp[i] = 1
        if i >= 2 * x:
            prefix_dp[i] += prefix_dp[i - 2 * x]
for i in range(n - 1, -1, -1):
    if string[i] == "X":
        suffix_dp[i] = 1
        if i + x < n:
            suffix_dp[i] += suffix_dp[i + x]
```

减去 1 是因为拼接位置被两边各算了一次。这里的“连续”是沿固定步长连续，遇到 . 就中断，不能随意跳过中间本该属于链的点。

 每个 x 扫描两遍字符串，总时间 O(n²)，辅助空间 O(n)。最终还要满足好的子序列至少有两个位置，源码在 X 少于两个时提前输出 0。
