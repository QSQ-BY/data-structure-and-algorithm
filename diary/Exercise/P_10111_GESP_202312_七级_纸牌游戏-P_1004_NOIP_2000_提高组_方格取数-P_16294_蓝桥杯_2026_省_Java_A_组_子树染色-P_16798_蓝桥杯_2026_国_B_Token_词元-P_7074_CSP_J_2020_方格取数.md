## P10111 纸牌游戏：换牌次数决定下一次的费用

这题的状态是 `dp[i][j][k]`：进行了 `i` 轮，现在持有牌 `j`，已经换过 `k` 次牌时的最大分数。牌型只有三种，但换牌费用与第几次换牌有关，所以不能只保留当前牌。

不换牌就从上一轮同牌型、同次数的状态转移；换牌则枚举之前不同的牌型，从 `k-1` 次换牌的状态扣掉 `b[k-1]`，再加本轮得分。不可达状态初始化为负无穷，避免把不存在的换牌历史当成可行方案。牌型数是常数，当前时间和空间都是 $O(n^2)$。

## P1004 方格取数：把往返改成两个人同步走

往返路径分别算最优，会把重复收益处理错。我把它们看成两个人同时从左上角向右下角走，每次各走一步。两人走过相同步数，行号与列号的和也相同，记为 `s`，位置便能写成 `(row1,s-row1)` 与 `(row2,s-row2)`。

```python
best = max(
    dp[s - 1][row1 - 1][row2 - 1],
    dp[s - 1][row1 - 1][row2],
    dp[s - 1][row1][row2 - 1],
    dp[s - 1][row1][row2]
)
gain = g[row1][col1]
if(row1 != row2):
    gain+= g[row2][col2]
dp[s][row1][row2] = best + gain
```

四种前驱对应两个人分别从上面或左面走来。收益先加第一个人的格子，只有两人不在同一格时才加第二份。同一个 `s` 上，行号相等就意味着列号也相等，所以只比较行号即可判断重合。

四个坐标压成三个维度后，时间是 $O(n^3)$，当前保留全部步数层的空间也是 $O(n^3)$。重合位置允许经过，只是收益记一次。

## P16294 子树染色：先处理孩子，再合并到父亲

讨论时我专门问了它属于图论的什么知识。代码先建立父子关系和父亲在前的遍历顺序，再倒序处理，得到树形 DP 所需的孩子先完成的顺序。

```python
for u in reversed(order):
    if key[u]:
        dp[u] = max(dp[u], (size[u] + 1) // 2)

    p = parent[u]
    if p:
        size[p] += size[u]
        dp[p] += dp[u]
```

`size[u]` 统计子树大小，`dp[u]` 汇总满足这棵子树内要求至少需要染色的节点数。不同孩子的子树不相交，它们的最低要求可以相加；当前节点也是关键点时，还要满足整棵子树至少染色一半的要求，因此与 `(size[u]+1)//2` 取较大值。

我还在补树形 DP 的基础，这份实现适合确认处理顺序：计算父亲时，孩子的大小与状态必须已经确定。整棵树只遍历常数次，时间和空间都是 $O(n)$。

## P16798 Token 词元：最后一个位置的值影响下一步

源码先把原数组转换成相邻比较得到的 `c`，再定义 `dp[i][j]` 为前 `i` 个位置、最后一个值为 `j` 时的最小总和，`j` 只取 1、2、3。

相邻 `c` 上升时，新值必须比上一个大；下降时必须小；相等时不附加大小约束。保存最后一个值，是为了判断下一对是否满足关系。只保存前缀最小总和，会丢掉这个边界信息。每个位置只有常数种状态与转移，总时间为 $O(n)$。

## P7074 方格取数：每列分别向下、向上扫描

这道题允许向上、向下、向右走，却不能重复经过格子。一旦向右离开一列就无法回来；同一列里上下折返又会经过旧格子，因此一列内的有效行走方向只能保持一致。

```python
#向下走
for i in range(n):
    down[i] = dp[i][j-1]
    if(i>0):
        down[i] = max(down[i],down[i-1])
    down[i] += g[i][j]
#向上走
for i in range(n-1,-1,-1):
    up[i] = dp[i][j-1]
    if i + 1 < n:
        up[i] = max(up[i], up[i+1])
    up[i] += g[i][j]

for i in range(n):
    dp[i][j] = max(down[i],up[i])
```

`down` 从上向下接收本列上方的状态，`up` 从下向上接收本列下方的状态，两次扫描都可以从上一列直接进入。最后合并两个方向，不让它们在同一列中互相更新。负数格子也可能必须经过，所以不可达状态仍用负无穷。

每列只做常数次线性扫描，总时间为 $O(nm)$。我问过四个方向都允许怎么办：那时就失去了列之间单向推进的依赖关系，不能把这里的两次扫描直接照搬过去。
