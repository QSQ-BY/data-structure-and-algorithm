## P2842 纸币问题 1：当前这一种可以重复使用

第一题求最少张数。我用 `dp[i][j]` 表示前 `i` 种纸币凑出金额 `j` 的最少张数。金额为 0 时不需要纸币，其他不可达状态初始化为正无穷。

```python
for i in range(1,n+1):
    for j in range(1,target+1):
        dp[i][j] = min(dp[i-1][j],dp[i][j])
        if(arr[i] > j):
            continue
        dp[i][j] = min(dp[i][j],dp[i][j-arr[i]] + 1)
```

不用当前面额来自上一行；使用一张时，来自本行的 `dp[i][j-arr[i]]`，再加 1。来源在本行，意味着可以继续使用当前面额，所以是完全背包。当前二维实现时间、空间都是 $O(nV)$。

## P2840 纸币问题 2：把最后支付的一张接在序列后面

第二题数支付序列，不同顺序算不同方案。我把金额放在外层，枚举最后支付的面额：

```python
for j in range(1, target + 1):
    for cur in money:
        if cur <= j:
            dp[j] += dp[j-cur]
    dp[j] %= MOD
```

`dp[0]=1` 表示空序列。每个凑出 `j-cur` 的序列，都能在末尾接一张 `cur`，形成凑出 `j` 的序列。最后一张不同，或者前面的顺序不同，都会分别计入。时间为 $O(nV)$，空间为 $O(V)$。

## P2834 纸币问题 3：按面额阶段统计组合

第三题统计各面额使用数量组成的方案，不再区分支付顺序。当前写法保留二维状态：

```python
for i in range(1, n + 1):
    cur = money[i]
    for j in range(target + 1):
        dp[i][j] = dp[i-1][j]
        if cur <= j:
            dp[i][j] += dp[i][j-cur]
```

`dp[i-1][j]` 是不使用第 `i` 种面额，`dp[i][j-cur]` 是至少使用一张。先限制可用面额，再更新金额，就不会把同一组合因为排列顺序不同重复加入。

用面额 1、2 凑出 3：第二题计入 `1+1+1`、`1+2`、`2+1` 三个序列，第三题只计入三张 1，以及一张 1 加一张 2 两种组合。循环顺序的区别来自计数对象，不能只当成可以随意交换循环的背包模板。当前二维数组有 $O(nV)$ 个状态。
