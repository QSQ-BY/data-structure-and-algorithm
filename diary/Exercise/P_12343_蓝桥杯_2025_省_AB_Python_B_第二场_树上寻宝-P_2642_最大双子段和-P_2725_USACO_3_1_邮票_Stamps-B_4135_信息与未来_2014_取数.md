## P12343 树上寻宝：每步走 1 或 2 条边等价于深度不超过 $2k$

题目允许从根结点 1 出发走不超过 $k$ 步，每步可以走 1 条或 2 条边。我在代码里一开始还建了一个 `step_two` 邻接表，打算显式存跳两边的关系，但往下写的时候反应过来根本不需要额外建图：既然单步能走 1 条边也能走 2 条边，那么只要树上某个结点到根的距离不超过 $2k$，就一定能拆成不超过 $k$ 步到达。

```python
ans = 0
stack = [(1,0,0)]#当前节点，父亲节点，步数
while stack:
    u,parent,step = stack.pop()
    ans += w[u]
    if(step >= 2*k):
        continue
    for v in g[u]:
        if(v != parent):
            stack.append((v,u,step+1))
print(ans)
```

这里栈里的 `step` 直接记经过的边数。用显式栈做 DFS 可以顺手避开 Python 在 $n \le 10^5$ 时的递归深度限制；`parent` 用来防止在无向树上走回头路。当 `step >= 2*k` 时直接截断，不再往子树扩展，每个合法结点只入栈一次，时间和空间复杂度都是 $O(n)$。

## P2642 最大双子段和：在最大 $k$ 子段和模板里留出至少一个间隔

做这题前我刚回头看了一眼 [P10911 数位翻转](../../Exercise/dynamic_programming/P_10911_蓝桥杯_2024_国_B_数位翻转.py) 里的多段区间 DP，把内层起点收紧到了 `range(k, n + 1)`。到了 P2642，题目要求选出两个非空子段，而且中间至少要隔开一个数。我直接沿用了 `end[k][i]` 的状态定义——表示选完第 $k$ 段、且第 $k$ 段恰好在第 $i$ 个位置结束时的最大和，只需要把段与段之间的间隔约束改掉：

```python
end = [[float("-inf")] * (n + 1) for _ in range(limit + 1)]
for i in range(1, n + 1):
    end[1][i] = max(end[1][i - 1], 0) + arr[i - 1]
for k in range(2, limit + 1):
    best = float("-inf")
    for i in range(2 * k - 1, n + 1):
        best = max(best, end[k - 1][i - 2])
        end[k][i] = max(end[k][i - 1], best) + arr[i - 1]
```

和允许两段紧挨着的情况相比，这里改了三处细节：

1. 两段必须非空且数值可能全为负数，所以 `end` 和 `best` 的初值都要设成 `-inf`，不能像允许空选时那样从 0 起步。
2. 两个子段之间至少要隔开一个元素，第 $k$ 段如果在位置 $i$ 新开，第 $k-1$ 段最晚只能结束在 $i-2$，所以 `best` 每次并入的是 `end[k - 1][i - 2]`。
3. 选出 $k$ 段且每两段之间至少隔 1 个位置，最少需要 $2k-1$ 个元素，内层循环直接从 `2 * k - 1` 开始即可。

这里 `limit = 2`，外层只跑一轮，时间和空间复杂度都是 $O(n)$。

## P2725 邮票 Stamps：从按组合做最小堆枚举转到按金额做完全背包

这题求用不超过 $k$ 张邮票能拼出的最大连续面额（从 1 开始）。我一开始写的是 `solution1()`，用最小堆按总面额从小到大生成所有合法的邮票多重集：堆里存 `(value, cnt, index)`，每次固定只对当前组合里最大的那张邮票 `values[index]` 做两种扩展——要么把它替换成更大一号的面值 `values[index + 1]`，要么在张数未满 $k$ 时再追加一张 `values[index]`。这两种扩展都会让总面额严格变大，既能不重不漏地生成所有组合，又能保证从堆顶弹出的面额单调不减，一旦碰到 `dp[value - 1]` 还是 `False`，就说明连续区间断了。

这个思路本身是对的，但问题出在复杂度上：它是按“邮票组合”去搜的，不同组合就算拼出同一个金额也会分别入堆，状态数会随着 $n \le 50, k \le 200$ 呈组合数级别爆炸。所以在 `solution2()` 里，我把视角从枚举组合换成了按金额去重递推：

```python
    upper = k*values[-1]
    #对于每一个金额记录他最少需要多少张邮票
    dp = bytearray([k+1])*(upper+1)
    dp[0] = 0
    dp[1] = 1
    ans = upper
    for s in range(2,upper+1):
        best = k+1
        for v in values:
            if(v > s):
                break
            best = min(dp[s-v]+1,best)
            if(best == 1):
                break
        if(best > k):
            ans = s - 1
            break
        dp[s] = best
```

状态设成 `dp[s]`，表示凑出金额 $s$ 最少需要多少张邮票。排序后如果最小面值不是 1，连 1 分都凑不出来，直接输出 0。

因为 $k \le 200$，不可达状态统一用 `k + 1` 表示，所有状态值都不超过 201，正好可以用一个 `bytearray` 存下，既省内存又快。从小到大枚举金额 $s$ 时，一旦算出的最少张数 `best > k`，说明金额 $s$ 已经无法在 $k$ 张以内凑出，直接返回 `s - 1`。这样就把状态数压到了金额上界 $k \cdot \max(a_i) \le 2 \times 10^6$，时间复杂度 $O(n \cdot k \max a_i)$，空间复杂度 $O(k \max a_i)$。

## B4135 取数：每次必须连取两个且不能三连

每次必须取相邻的 2 个数，不能单取 1 个，也不能连续取超过 2 个。如果按单个位置设“取或不取”还要记录连续个数；不如直接把“相邻一对数”当成基本单位，设 `dp[i]` 表示必须选下标 `i-1` 和 `i` 这一对时的最大总和：

```python
dp = [float("-inf")] * n

dp[1] = arr[0] + arr[1]
if n >= 3:
    dp[2] = arr[1] + arr[2]
best = 0
for i in range(3, n):
    # 前一对的结束下标最多为 i-3
    best = max(best, dp[i - 3])
    dp[i] = arr[i - 1] + arr[i] + best
print(max(dp))
```

当前这一对占用了 `i-1` 和 `i`。如果前一对结束在 `i-2`，两对就会拼成 `i-3, i-2, i-1, i` 四个连续位置，违反不能多于 2 个连续数的规则；所以前一对的右端点最多只能到 `i-3`，中间至少隔开 `i-2` 这一个位置不选。

循环里用 `best` 维护 `dp[0..i-3]` 的前缀最大值，初值设为 0 表示当前这一对也可以作为第一对单独开始（题目中 $x_i \ge 1$，历史最大和不会比 0 更差）。单次推进只要常数时间，总时间复杂度 $O(n)$，空间复杂度 $O(n)$。
