# 从排列枚举到连通块复用：三道练习里的搜索状态

今天留下三道与搜索有关的练习。油滴扩展需要安排尝试顺序；01 迷宫与离开中山路则更在意一次遍历能留下什么信息。写到后面，我越来越觉得，“用 DFS 还是 BFS”只是表面选择，真正影响效率的是状态怎样表示、重复工作怎样消掉。

## P1378 油滴扩展：排列顺序决定可用半径

这题不能先给每个点独立算一个半径。后放的油滴不仅受矩形边界限制，还会碰到已经扩展完成的圆；换一种放置顺序，前后约束随之改变，因此需要枚举所有点的排列。

```python
for pos, i in enumerate(arr):
    x, y = pot[i]
    r = min(x, a - x, y, b - y)
    for pre_pos in range(pos):
        j = arr[pre_pos]
        x2, y2 = pot[j]
        distance = math.hypot(x - x2, y - y2)
        r = min(r, distance - radius[j])
    r = max(0.0, r)
    radius[i] = r
    total_area += math.pi * r * r
```

`r` 先取点到四条边的最短距离，再与所有先放油滴留下的间隙比较。若点已经落入某个圆的覆盖范围，算出的间隙会是负数，此时半径只能取零。最后用矩形面积减去最大圆面积，并通过 `int(value + 0.5)` 完成正数的四舍五入。

当前写法对每个排列重新计算一次圆面积，时间复杂度是 $O(n!\,n^2)$。它没有复杂的剪枝，难点反而是把“先放的圆固定、后放的圆退让”准确写进半径计算。题面样例输出为 `50`。

## P1746 离开中山路：最短路要按层扩展

最后一题把 DFS 教学写法和实际提交的 BFS 放在了同一个文件里。DFS 可以穷举路径并维护当前最优值，但在 $1000\times1000$ 的地图上承担不起大量重复分支。BFS 从起点按距离一层层扩展，第一次取出终点时，队列里的层次顺序已经保证这就是最短距离。

这里还有一个容易忽略的细节：格子应在入队时标记，而不是出队时标记，否则同一个位置可能被多个相邻格重复加入队列。最坏情况下，BFS 的时间和空间都是 $O(n^2)$。题面样例输出为 `4`。

三道题连起来看，搜索顺序其实有两层含义：回溯中，它决定先探索哪条分支；图搜索中，它决定答案的距离层次和已知信息能否复用。接下来再遇到搜索题，我准备先问两个问题：当前选择会怎样限制后续状态，一次遍历的结果能不能留给后面的询问。
