# 等待开放的格子、环形灯带与分段求和

## P8693 大胖子走迷宫：把体型变化转成格子的开放时间

[源码](../../Exercise/backtrack_algorithm&search/P_8693_蓝桥杯_2019_国_AC_大胖子走迷宫.py)

人物会在 k、2k 时刻缩小。我不用把每一秒等待都放进队列，而是先检查一个中心点能否容纳 5×5、3×3 或 1×1 的身体，据此给出最早可以出发进入它的时间 ready。

 当前实现预处理了前两种体型的合法位置，再用最早到达时间做最短路。下面摘录每次扩展中确定门槛和更新时间的部分：

```python
if (2 <= nx < n-2 and 2 <= ny < n-2
        and vis1[nx-2][ny-2]):
    ready = 0
elif (1 <= nx < n-1 and 1 <= ny < n-1
        and vis2[nx-1][ny-1]):
    ready = k
else:
    ready = 2*k

next_step = max(step, ready) + 1

if next_step < s[nx][ny]:
    s[nx][ny] = next_step
    heappush(q, (next_step, nx, ny))
```

ready 分别取 0、k、2k，转移为 max(step, ready)+1。这表示必要时先在原地等到身体足够小，再移动一步。不能直接写 max(step+1, ready)，那会把“何时能开始这一步”和“何时抵达”混在一起。

 身体只会变小、位置限制只会放宽，所以更早到达同一个中心点可以等待，不会比更晚到达差。状态因此只需保存坐标。固定大小的预处理为 O(n²)，堆最短路为 O(n² log(n²))。

## P16796 灯带修补：把灯珠数量换成相邻关系数量

[源码](../../Exercise/binary_search/P_16796_蓝桥杯_2026_国_B_灯带修补.py)

环形灯带先复制一遍，跨越末尾的连续段就能表示成普通区间。判断一段能否修好时，真正要统计的是相邻灯珠之间不稳定的边。

 长度为 length 的一段有 length-1 条边。stable 保存每条边是否稳定，prefix 统计稳定边数，所以不稳定边数就是 length-1-s。

```python
#检查是否能够选出一段长度为length的灯带并保证稳定
def check(length):
    for window_left in range(2*n - length):
        window_right = window_left + length - 1
        s = prefix[window_right] - prefix[window_left]
        if length - 1 - s <= m:
            return True
    return False
```

这里的前缀和范围比灯珠范围少一位，是因为统计对象已经换成边。修补次数不超过 m 就可行。缩短一个可修补区间不会增加坏边，因此可二分最大长度；每轮线性枚举区间，总时间 O(n log n)，空间 O(n)。

 我把“长度 L 有 L-1 条内部相邻关系”单独记下来，之后做环和链上的区间统计时可以先确认统计的是点还是边。

## P8762 123：先定位完整段，再计算最后一段的前缀

[源码](../../Exercise/math/P_8762_蓝桥杯_2021_国_ABC_123.py)

序列按 1；1,2；1,2,3；……拼接，位置很大时不能真的生成数组。我把前 x 项拆成前 k 个完整段和下一段的前 q 项。

 前 k 段的元素数量为 k(k+1)/2，完整段之和为 k(k+1)(k+2)/6，余下 q 项之和为 q(q+1)/2。源码用整数平方根直接定位 k：

```python
k = (isqrt(8 * x + 1) - 1) // 2
q = x - k * (k + 1) // 2
return k * (k + 1) * (k + 2) // 6 + q * (q + 1) // 2
```

整数平方根避免了大位置处浮点取整的误差。区间答案再用 prefix_sum(r)-prefix_sum(l-1) 得到。每次查询只需固定次数的整数运算；若计入大整数成本，还取决于输入数的位数，不能把任意精度运算都视作严格常数时间。
