# 搜索上界、LQ 分界与有序序列生成

## P5194 Scales：剩余重量和同时提供剪枝与直接结算

[源码](../../Exercise/backtrack_algorithm&search/P_5194_USACO_05_DEC_Scales_S.py)

容量很大时，不适合按容量建立普通背包表。题目保证砝码已按重量排序，并且从第三个起，每个至少等于前两个之和；去掉超过容量 C 的砝码后，可用数量只会有 O(log C) 级别。我从当前可用的最大砝码开始搜索选或不选，prefix[k] 表示剩余前 k 个砝码全部选上的重量。

 于是 total+prefix[k] 是当前分支能达到的上界：

```python
upper = total + prefix[k]

# 全选也无法改进答案
if upper <= ans:
    return

# 全选也不超重，直接得到当前分支的最优解
if upper <= limit:
    ans = max(upper,ans)
    return

# 优先选当前最大的砝码
if total + weights[k] <= limit:
    dfs(k - 1, total + weights[k])

# 不选当前砝码
dfs(k - 1, total)
```

如果上界不超过已有答案，这一分支无论怎么选都无法改进；如果全选也不超重，就可以直接用全选的结果结束，不必再拆成更多子分支。只有剩余总量足够大、却不能直接全选时，才继续分支。

 先尝试选当前大砝码，有助于尽早得到较好的答案，再用它剪掉其他分支。若保留下来 m 个砝码，搜索的保守上界仍是 O(2^m)，递归深度 O(m)，前缀和界限继续减少实际访问量；读取原输入仍需 O(N)。这里能用搜索，还依赖题目给出的重量增长条件。

## P16236 LQ 聚合：问号的最优安排可以只枚举一个分界

[源码](../../Exercise/Ad-hoc/P_16236_蓝桥杯_2026_省_B_LQ_聚合.py)

目标是让前 L 后 Q 的配对尽量多。对两个问号，如果前面选 Q、后面选 L，把它们交换成 L、Q 不会减少配对。因此可以把问号按位置排列，只枚举前 k 个填 L、剩下填 Q 的分界。

 源码先让所有问号都填 Q，再从左向右逐个改成 L。leftL、rightQ 分别统计固定字符带来的两侧贡献。

```python
# 依次把前面的 ? 改成 L
for k in range(1, m + 1):
    x = pos[k - 1]

    # Q -> L:
    # 新增：这个 L 和后面的 Q
    # 减少：这个位置原本 Q 和前面的 L
    cur += rightQ[x] - leftL[x]

    # ?之间的贡献：
    # 前 k 个 ? 是 L，后 m-k 个 ? 是 Q
    now = cur + k * (m - k)
    ans = max(ans, now)
```

把一个问号从 Q 改成 L，与固定字符之间的贡献变化是 rightQ[x]-leftL[x]；问号彼此之间的贡献单独记为 k(m-k)，避免重复计算。

 每移动一次分界只更新常数项，预处理和枚举都为 O(n)，空间 O(n)。这比直接枚举每个问号填哪种字符少了指数级的组合，减少枚举的依据是交换后配对数不会下降。

## P1631 序列合并：固定 A[i] 后，每一行都是有序候选

[源码](../../Exercise/Ad-hoc/P_1631_序列合并.py)

两个数组有序时，固定 A[i]，就得到 A[i]+B[0]、A[i]+B[1]……这一条递增序列。要输出最小的 n 个和，可以把每一行当前还未取出的最小项放进堆。

 当前实现每弹出一项，只补入同一行的下一项：

```python
for _ in range(n):
    s,i,j=heapq.heappop(heap)

    ans.append(s)

    if j+1<n:
        heapq.heappush(
            heap,
            (A[i]+B[j+1],i,j+1)
        )
```

堆里保存和值、行号和列号。下一项仍用 A[i]+B[j+1] 计算，行保持不变，列前进一格。重复和值对应不同配对，需要分别保留。

 初始每行放一项，之后取 n 次，时间 O(n log n)，堆和输出数组空间 O(n)。这份题目要输出前 n 小的全部和值；与只问第 k 小的题相比，所需生成数量本身就是输出规模。

## P1978 集合：普通并查集统计冲突链长度就够了

[源码](../../Exercise/unionset/P_1978_集合.py)

我问过能否用带权并查集，最后采用普通并查集补完。若 x 和 kx 都在原集合中，就在它们之间连一条冲突边，表示不能同时选。

 k≥2，数值不为零且互不相同，所以每个数至多有一个乘 k 的后继、一个除 k 的前驱；沿边绝对值严格增大，不会成环。因此每个连通分量都是一条链，长度为 s 时最多隔点选出 (s+1)//2 个。

 源码用哈希表找 value*k 是否存在，再用普通并查集合并；最后只对根节点累计这个公式。这里需要的是每条链的长度，没有查询节点之间的倍数距离，所以不必在并查集里额外维护权值。时间按哈希平均 O(1)、并查集摊还计算为 O(nα(n))，空间 O(n)。
