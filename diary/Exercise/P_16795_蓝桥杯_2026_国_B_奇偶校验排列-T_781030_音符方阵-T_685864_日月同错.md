## P16795：先决定每个位置的奇偶性，再填最小可用数字

[源码](../../Exercise/math/P_16795_蓝桥杯_2026_国_B_奇偶校验排列.py)

校验串的 0 表示相邻两数同奇偶，1 表示异奇偶。因此，只要第一位的奇偶性确定，后面所有位置的奇偶性就被确定，最多只有两种模式。

我先尝试首位为奇数的模式，检查它需要的奇数、偶数数量是否分别等于 `(n+1)//2`、`n//2`。数量匹配后，每类位置依次填入最小的未用数字：

```python
    odd = 1
    even = 2
    ans = []
    for x in parity:
        if(x == 1):
            ans.append(odd)
            odd += 2
        else:
            ans.append(even)
            even += 2
    return ans
```

在奇偶模式固定后，同类数字互换不会影响校验串。若当前位置没有使用该类最小的剩余数，把它从后面换过来，前缀会更小而合法性不变，因此按顺序填数就是字典序最小。

首位为奇数且可行时，第一项可以是 1；首位为偶数的方案第一项至少是 2。所以先尝试 `build(1)`，只有不可行时再尝试 `build(0)`。两次都不满足数量要求才无解。

时间和空间都是 O(n)。这题的构造分两层：先让类别数量满足约束，再在同类元素中用字典序贪心，没必要直接搜索 n 个数的排列。

## T781030：用 gcd 同时满足行和列的倍数位置要求

[源码](../../Exercise/math/T_781030_音符方阵.py)

音符方阵要求对每个 k，恰好有一行的所有 k 倍数列都填 k，也恰好有一列的所有 k 倍数行都填 k。我使用对称构造 `a[i][j]=gcd(i,j)`。

```python
def solve(n:int):
    g = [[0]*(n+1)for _ in range(n+1)]
    for i in range(1,n+1):
        for j in range(1,n+1):
            g[i][j] = math.gcd(i,j)

    for i in range(1,n+1):
        g[i].pop(0)
        print(*g[i])
```

存在性很直接：第 k 行在列 k、2k、3k……处都有 gcd(k,tk)=k，第 k 列也一样。数值始终在 1 到 n 之间。

需要补上的证明是“恰好一行”。假设第 r 行也满足 k 的条件，那么在第 k 列必须有 gcd(r,k)=k，即 k 整除 r。如果 r≠k，则 r>k；此时第 r 列也是 k 的倍数列，但 a[r][r]=r≠k，产生矛盾。因此只有第 k 行满足，列的唯一性由对称性得到。

源码逐格调用 gcd，按通常的欧几里得算法界估算为 O(n² log n)，当前保存完整矩阵，空间 O(n²)，输出本身需要 n² 个元素。我要保留的是对存在性和唯一性的分别检查：把指定行构造出来以后，还得排除其他行也意外满足条件。

## T685864：每个不平衡区间需要一个内部翻转边界

[源码](../../Exercise/Ad-hoc/T_685864_日月同错.py)

日月同错给出互不相交的区间，要求每个区间内部的 0、1 数量相等。最初的代码把目标写成了让不同区间的 1 数量相同，也只考虑整段翻转；重新看清操作后，任意 `[L,R]` 都可以翻转，包括从一个给定区间的中间跨到另一个区间的中间。

奇数长度一定无解。其余情况下，设原本不平衡的区间有 k 个，答案是 ⌈k/2⌉。代码只需要数出 k：

```python
for _ in range(m):
    l, r = map(int, input().split())
    length = r - l + 1

    if length % 2:
        print(-1)
        sys.exit()

    one_cnt = s.count(b'1', l - 1, r)
    if one_cnt * 2 != length:
        ans += 1
print((ans + 1) // 2)
```

证明先看一个区间。把 1 记成 +1、0 记成 -1，总和为 D；翻转总和为 x 的部分后，整个区间变成 D-2x。偶数长度保证 D 为偶数，前缀和从 0 走到 D，每一步只加减 1，必然经过 D/2。这个位置把区间分成和都为 D/2 的前后两部分，翻转任意一部分都能使总和归零。

把不平衡区间按位置两两配对，一次翻转从左边区间的合适后缀开始，到右边区间的合适前缀结束，就能修好这一对。夹在它们之间的给定区间原本都已平衡，整体翻转只交换 0、1 数量，仍然平衡；没有区间约束的位置可以自由改变。若剩下一个，再单独翻转一次。

下界也要说明：一个不平衡区间如果始终只是整体翻转或完全不翻，永远不会平衡。它必须至少包含一个操作的内部翻转边界。一次操作只有两个边界，而给定区间互不相交，所以至少需要 ⌈k/2⌉ 次。构造达到这个下界，最优性才完整。

这里不用实际寻找分割点，也不用把区间排序。`count` 只扫描当前给定区间，所有区间互不相交，总扫描长度不超过 n，因此时间 O(n+m)，除保存字符串外只需常数额外空间。最后留下的几行统计代码，背后依赖的是前缀和能走到 D/2，以及两个翻转边界能配给两个区间。
