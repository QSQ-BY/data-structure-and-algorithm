## P12842 土地整平计划：相邻去重后按内部段数计费

把整片土地都变成高度 $H$，每次可以把一段区间推平为 $H$，代价是 $H$。如果目标高度 $H$ 不在原数组里，至少也要整段刷一次，肯定不如直接选原数组里已有的高度划算。

先把相邻等高的位置合并成一个点。去重之后，如果选某个高度 $v$ 作为最终高度，那么数组中每一个值为 $v$ 的位置就像隔板一样，把其余非 $v$ 的位置切成了若干个连续段：

```python
s = {}
for i in range(n):
    number = arr[i]
    if(number in s):
        if(i == n-1):
            continue
        s[number] += 1
    else:
        if(i == 0 or i == n-1):
            s[number] = 0
        else:
            s[number] = 1
ans = float("inf")
for number,cnt in s.items():
    ans = min(ans,number*(cnt+1))
print(ans)
```

去重后任意相邻两项都不相等。如果某个数值 $v$ 出现在首尾（`i == 0` 或 `i == n - 1`），它靠着边界的那一侧不会多切出新的非 $v$ 区间；而每次出现在中间位置，就会使需要推平的区间数加 1。代码里用 `cnt + 1` 统计把全数组变成 `number` 所需的操作次数，乘上单次代价 `number` 后取最小值，时间复杂度 $O(n)$。

## P4170 涂色：首尾同色时顺带刷出右端点

长度为 $n \le 50$ 的木板，每次可以把一段区间刷成同一种颜色，后涂的覆盖先涂的。设 `dp[l][r]` 表示只涂好闭区间 `[l, r]` 最少需要几次操作：

```python
for length in range(2, n + 1):
    for l in range(n - length + 1):
        r = l + length - 1

        if string[l] == string[r]:
            dp[l][r] = dp[l][r - 1]
        else:
            dp[l][r] = length
            for k in range(l, r):
                dp[l][r] = min(
                    dp[l][r],
                    dp[l][k] + dp[k + 1][r]
                )
```

关键在于 `string[l] == string[r]` 的分支：当区间首尾目标颜色相同时，第一次在涂左端点 `l` 的那一步，完全可以把刷子直接拉到 `r`，之后在中间 `[l + 1, r - 1]` 覆盖其他颜色即可，右端点 `r` 不需要额外多花一次操作，因此 `dp[l][r] = dp[l][r - 1]`。首尾不同色时，两端的底色不可能由同一次刷涂留存下来，直接枚举分界点 $k$ 把区间拆成两半合并，时间复杂度 $O(n^3)$。

## P2679 子串：拆开“当前位置必须收尾”与“前缀总方案数”两张表

从字符串 $A$ 中按顺序取出 $k$ 个互不重叠的非空子串，拼成字符串 $B$。匹配到 $a[i-1] == b[j-1]$ 时，既可以把 $a[i-1]$ 接在紧挨着的 $a[i-2]$ 后面归入同一个子串，也可以单独新开第 $t$ 个子串。这意味着“是否能延续上一段”严格取决于 $a[i-2]$ 当时有没有被选中。

所以我同时维护了两张表：`end[i][j][t]` 表示 $A$ 的前 $i$ 个字符匹配 $B$ 的前 $j$ 个字符、分成了 $t$ 段，且第 $t$ 段恰好在 $a[i-1]$ 结尾的方案数；`dp[i][j][t]` 则不要求第 $t$ 段在 $a[i-1]$ 结尾，统计前 $i$ 个位置里的所有合法方案：

```python
for i in range(1,n+1):
    cur = i%2
    pre = 1 - cur
    dp[cur] = [[0] * (k + 1) for _ in range(m + 1)]
    end[cur] = [[0] * (k + 1) for _ in range(m + 1)]
    dp[cur][0][0] = 1
    for j in range(1,min(m,i)+1):
        for t in range(1,min(j,k) + 1):
            if(a[i-1] == b[j-1]):
                #第一种选择直接延续在上一个的后面，或者是直接新开一个段
                end[cur][j][t] = (end[pre][j-1][t] + dp[pre][j-1][t-1])%MOD

            dp[cur][j][t] = (dp[pre][j][t] + end[cur][j][t])%MOD
```

当 `a[i-1] == b[j-1]` 时，`end[cur][j][t]` 的两条来源非常清晰：接在 `a[i-2]` 后面就加 `end[pre][j-1][t]`，新开一段就加 `dp[pre][j-1][t-1]`。然后再把不选 `a[i-1]` 的 `dp[pre][j][t]` 和选了 `a[i-1]` 的 `end[cur][j][t]` 汇总成 `dp[cur][j][t]`。因为 $n = 1000, m = 200, k = 200$，三维数组直接开会爆内存，第一维按 `i % 2` 滚动后空间降为 $O(mk)$，时间复杂度 $O(nmk)$。

## P10556 Make Them Straight：调和级数剪枝枚举公差与首项

把数组改成公差为 $k \ge 0$ 的非负等差数列，修改下标 $i$ 的代价是 $b_i$，求最小总代价。反过来想就是求“最多能保住多少代价的数不改”。

一旦固定了公差 $k$，某个原位置 $a_i$ 如果不修改，那么整个等差数列的首项就唯一确定为 $\text{first} = a_i - i \cdot k$。さらに题目要求改变后的等差数列每一项非负且单调不降，首项必须满足 $\text{first} \ge 0$，即 $i \cdot k \le a_i \le \max(a)$：

```python
# k > 0 枚举公差k
for k in range(1, M + 1):
    # 下标 0 对应的首项始终是 a[0]
    saved = {a[0]: b[0]}

    limit = min(n - 1, M // k)
    for i in range(1, limit + 1):
        first = a[i] - i * k#查找第i个数字对应的对开头的数字，第i个数字所在的序列在公差为k的情况下最开头的数字一定是a[i] - i*k

        if first < 0:
            continue

        current = saved.get(first, 0) + b[i]
        saved[first] = current
        best = max(best, current)
```

$k = 0$ 时单独用哈希表按数值统计一遍最大保留代价。当 $k > 0$ 时，下标 $i$ 一旦超过 $M // k$，算出来的首项 $\text{first} = a_i - i \cdot k$ 就必然小于 0，不可能保留。因此内层循环只需要跑到 `min(n - 1, M // k)`。这个上界让总循环次数变成了 $\sum_{k=1}^{M} \frac{M}{k} = O(M \log M)$，配合哈希表按首项 `first` 聚合保留代价，直接在线性对数时间内拿到最优解。

## U558844 小苯的排列计数：按前缀最小值分段计算比当前极小值更大的剩余池

给定排列每个位置的前缀最小值 `prefix[i]`，求合法排列数。首先，合法的 `prefix` 必须单调不升，且最后一个位置 `prefix[-1]` 必须等于 1。

把相等的连续前缀最小值合并成一个区间 `(value, left, right)`。在区间左端点 `left` 处，前缀最小值刚刚刷新为 `value`，所以排列在下标 `left` 的位置只能填 `value` 本身；而区间内部剩下的 `slots = right - left` 个空位，都没有刷新前缀最小值，说明这些位置填的数全都严格大于 `value`：

```python
    ans = 1
    for value, left, right in intervals:
        #可选的数字的个数，其中n-value是因为所有的值都必须大于value，减去left是因为left前的值都已经去定下来了
        available = n - value - left
        #当前这一个区间之内即将确定的数字的个数
        slots = right - left

        if available < slots:
            ans = 0
            break

        for j in range(slots):
            ans = ans * (available - j) % MOD
```

从左往右按段填数时，因为 `prefix` 严格递减，前面下标 $0 \sim \text{left}-1$ 填过的 $\text{left}$ 个数一定全都大于当前的 `value`（上一个区间的最小值已经大于 `value`，它内部填的数更大于它）。而在 $1 \sim n$ 中，严格大于 `value` 的数一共有 $n - \text{value}$ 个，扣掉前面已经用掉的 $\text{left}$ 个，当前真正还能拿来填这 `slots` 个空位的候选数就恰好有 $\text{available} = n - \text{value} - \text{left}$ 个，直接乘上排列数 $A_{\text{available}}^{\text{slots}}$ 即可，时间复杂度 $O(n)$。

## P12139 黑白棋：把三连、数量与行列查重拆到不同时机剪枝

$6 \times 6$ 的黑白棋填空题，要求每行每列 0 和 1 各占 3 个、不能出现连续三个同色棋子、且行与行互不相同、列与列互不相同。我按 `index` 从 $0$ 到 $35$ 逐格爆搜，并把三类规则放在不同的时间点拦截：

```python
def check(x,y):
    row = g[x]
    column = [g[i][y] for i in range(6)]

    for line in (row,column):
        # 每种颜色最多三个；填满后自然各有三个。
        if(line.count(0) > 3 or line.count(1) > 3):
            return False

    # 遍历到行末、列末时，用集合检查重复。
    if(y == 5):
        row_code = "".join(map(str,row))
        if(row_code in row_set):
            return False
    if(x == 5):
        column_code = "".join(map(str,column))
        if(column_code in column_set):
            return False

    # 全部检查通过后再加入，避免失败时留下部分状态。
    if(y == 5):
        row_set.add(row_code)
    if(x == 5):
        column_set.add(column_code)
    return True
```

1. **三连限制**：在填 $(x, y)$ 之前，直接看上方两格 `(x-1, y), (x-2, y)` 和左方两格 `(x, y-1), (x, y-2)`。注意棋盘上原本预填好的固定棋子同样可能跟前面刚填的格子撞出三连，所以在 `g[x][y] != -1` 的分支里也要先过一遍 `one_available` 和 `zero_available` 检查。
2. **颜色数量**：每填一格，只要所在行或列的 `0` 或 `1` 计数超过 3 就立刻剪枝。
3. **行列唯一性**：只有当 `y == 5`（整行填满）或 `x == 5`（整列填满）时，才把整行/整列转成字符串去 `row_set`、`column_set` 查重。而且必须等行列两项检查都通过之后再往集合里 `add`，避免同一格同时触发行末和列末时，其中一个失败却把另一个留在了集合里污染回溯状态。
