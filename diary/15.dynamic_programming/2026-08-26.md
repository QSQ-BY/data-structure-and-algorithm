# 2026-08-26：用两道难题收尾动态规划

今天正式结束了动态规划这一章。最后写的两道题都不轻松：一道是在 01 背包上维护前 \(K\) 优解，另一道是用斜率优化解决仓库建设。它们的难点不太一样，前者要改变 DP 状态里保存的信息，后者则要先把转移式推到适合维护的形状。

## P1858：01 背包的前 K 优解

这道题整体没有想象中那么难。普通 01 背包的 `dp[capacity]` 只保存一个最优值，这里把一个数换成一个数组，让它按价值从大到小保存恰好装满当前容量的前 \(K\) 个方案。

处理一个新物品时，当前容量的候选方案来自两组：不选当前物品的旧数组，以及选择当前物品后，由 `dp[capacity - weight]` 中每个值加上 `value` 得到的新数组。两组本来都有序，所以不必把所有结果放在一起重新排序，只需要像归并排序一样从头比较，留下前 \(K\) 大的值。

```python
temp = [0]
index1 = 1
index2 = 1
n1 = dp[j][0]
n2 = dp[j-weight][0]
temp[0] = min(k,n1+n2)
while((index1 <= n1 or index2 <= n2) and len(temp) < k+1):
    #数组2为空
    if(index2 > n2 or (index1<=n1 and index2<=n2 and dp[j][index1] >= dp[j - weight][index2] + value)):
        temp.append(dp[j][index1])
        index1 += 1
    else:
        temp.append(dp[j - weight][index2] + value)
        index2 += 1
dp[j] = temp
```

这里依旧要倒序枚举容量，保证每件物品最多选择一次。变化只发生在状态内容和合并过程上：每个容量从维护一个数变成维护至多 \(K\) 个数，单次转移用两个指针完成。因此时间复杂度是 \(O(NVK)\)，空间复杂度是 \(O(VK)\)。

这道题让我重新看了一遍“状态存什么”这件事。DP 的框架没有变，但一个状态未必只能给出唯一最优值；只要转移后的候选集合能够有序合并，同样可以保留前若干个答案。

## P2120：仓库建设与斜率优化

只要涉及斜率优化，题目就很难轻松下来。最先拦路的是公式推导，我也是完整听完老师讲解后才开始写。好在数学关系确定之后，实现流程很明确：先更新队首，选择当前最优决策；再计算 `dp[i]`；随后更新队尾，去掉不可能再成为最优决策的点；最后把新状态压入队列。

设 `s[i]` 是产品数量的前缀和，`t[i]` 是 `x[i] * p[i]` 的前缀和。若上一个建仓库的位置是 `j`，转移为：

```text
dp[i] = dp[j] + x[i] * (s[i] - s[j]) - t[i] + t[j] + c[i]
```

把只与 `i` 有关的部分移到外面，需要比较的部分就变成：

```text
dp[j] + t[j] - x[i] * s[j]
```

这样，历史状态可以看成横坐标为 `s[j]`、纵坐标为 `dp[j] + t[j]` 的点，当前的 `x[i]` 则决定查询斜率。代码中的队列维护也正好对应这个推导：

```python
for i in range(1,n+1):
    while(len(q) >= 2 and cmp1(q[0],q[1]) == True):
        q.popleft()
    calculate(i,q[0])
    while(len(q)>=2 and cmp2(i,q[-1],q[-1],q[-2]) == True):
        q.pop()
    q.append(i)

last_has_p = n
while last_has_p >= 1 and p[last_has_p] == 0:
    last_has_p -= 1
ans = min(dp[max(1, last_has_p) : n + 1])
```

这道题还有两个容易漏掉的地方。

第一个是 `s[i]` 只能保证不下降，不能保证严格递增。只要某个工厂的 `p[i]` 为 0，就可能出现两个状态的横坐标相同，斜率公式的分母也会变成 0。因此不能照搬之前“古老的打字机”那道题，直接写一个带除法的 `slope` 函数，而要使用交叉相乘比较，并正确处理横坐标相同的情况。

第二个坑在最终答案。`dp[i]` 表示前 `i` 个位置已经处理完，并且在位置 `i` 建设仓库的最小费用。一开始很容易认为答案必然是 `dp[n]`，因为产品只能向编号更大的位置运输。实际上，如果末尾几个工厂没有产品，就没有必要强制在第 `n` 个工厂建仓库。最后一座仓库可以位于“最后一个有产品的工厂”到 `n` 之间，所以还要对这一段的 `dp` 再取一次最小值。
