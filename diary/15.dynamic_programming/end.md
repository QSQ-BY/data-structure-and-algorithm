# 动态规划学习结束：先停下来沉淀

到这里，动态规划这一章的学习正式结束了，我这一阶段的算法学习也暂时告一段落。

后面当然还有很多内容。字符串匹配、树形 DP 是更深入的算法，树状数组和线段树也是迟早要补上的数据结构。不过我现在不想立刻追着下一章往前赶。前面已经学过不少算法和数据结构，如果只是不断接触新名词，原来的内容很容易停留在“当时听懂了”的程度，真正做题时还是未必能认出来。

接下来这段时间，我想先把速度放慢一点，不再按章节继续学习新内容，而是认真刷题。遇到题目时，试着自己判断它属于哪种模型，状态应该怎么定义，复杂度能不能过；做错以后也回头看看，问题究竟出在思路、状态还是边界上。比起再学几个新模板，我现在更需要把已经接触过的东西用熟。

这次停下来可能会持续很久。等这些算法不再只是分散的章节，而是真的能够在题目里被我调用起来以后，我再回来继续后面的学习。
