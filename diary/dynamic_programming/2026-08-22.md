## 绝世好题：把前驱关系压到二进制位上

第一题是 P4310「绝世好题」。它和前一天做过的接龙数列很像，也让我想到最长上升子序列：都要维护一个类似 `len` 的数组，用已经处理过的状态更新当前答案。

如果按照传统 DP 来想，令 `dp[i]` 表示以第 `i` 个数结尾的最长合法子序列，就得遍历前面的每个数，检查按位与是否不为零。这样虽然容易写，但复杂度会到 `O(n²)`。接龙数列可以直接取出首位和末位，最长上升子序列也能借助递增关系二分查找；这道题看起来没有那么直接的“前驱编号”。

转折点在于重新解释“按位与不为零”：前后两个数至少存在一个共同为 `1` 的二进制位。因此，不必记住每个历史位置，只要记住“结尾数字的第 `j` 位为 `1` 时，最长子序列有多长”。代码里的 `best` 就是压缩后的 `len`：

```python
best = [0]*30
for number1 in arr:
    current = 1
    used_bits = []
    for j in range(30):
        #第j位数字为1
        if (number1 & (1<<j) != 0):
            used_bits.append(j)
            current = max(current,best[j]+1)
    for j in used_bits:
        best[j] = max(best[j],current)
```

处理当前数字时，先枚举它所有为 `1` 的位，从对应的 `best[j]` 中找出最长前驱，再把得到的 `current` 写回这些位。这里先收集 `used_bits`、后统一更新很重要，否则当前数字刚更新过某一位，又可能通过自己的另一位继续转移，相当于把同一个数字重复使用。

每个数字最多检查 30 个二进制位，复杂度从 `O(n²)` 降到 `O(30n)`，额外状态只有 30 个。这题让我更具体地看到，状态压缩前要先问：决定后续转移的究竟是完整的历史状态，还是历史状态身上的某个特征？这里需要保留的特征就是哪些二进制位为 `1`。

## 小苯的区间疑惑：让 i 待在区间中间

第二题是「小苯的区间疑惑」。我以前做过“以 `i` 结尾的最大子段和”，所以看到“必须包含 `i` 的最大区间和”时，脑子反而一下转不过来了。后来才发现，不需要重新发明一个状态，只要把熟悉的模型从左右两边各做一次。

`left[i]` 表示以 `i` 结尾的最大区间和，正向扫描即可得到：

```python
left = [0]*(n+2)
left[1] = arr[1]
for i in range(2,n+1):
    if(left[i-1] > 0):
        left[i] = arr[i]+left[i-1]
    elif(left[i-1]<=0):
        left[i] = arr[i]
```

再从右往左做一遍，得到以 `i` 开头的最大区间和 `right[i]`。把两部分拼起来，`i` 就自然落在区间中间：

```text
answer[i] = left[i] + right[i] - a[i]
```

最后减去 `a[i]`，是因为左右两段都包含它，直接相加会算两次。两遍扫描都是线性的，因此总复杂度为 `O(n)`。

题目把熟悉的“以 `i` 结尾”换成“包含 `i`”以后，我一开始就没能把两者接起来。以后再看到这种限制，我应该试着把目标位置放到中间，分别考虑它向左、向右能够取得的最优贡献，别急着把已有的一维状态硬扭成一个陌生模型。

## ABC472：前三题很快，D 题却走回了暴力

晚上的 ABC472，前三题比较顺，我大约 30 分钟就都解决了。到了 D 题，节奏突然断掉。题目要求统计哪些空格能在 `K` 步内到达安全格，我一开始沿用了最直接的想法：遍历每个格子，再去检查它和安全格之间的关系。最后的暴力做法只过了几个测试点。

其实我中间想过“站在每个安全点向外走”，这个方向已经很接近答案了，只是脑子里没有形成完整流程。我之前写 DFS 更多，对 BFS 的层次扩展不够敏感，于是没有继续追问：既然所有安全格地位相同，为什么不让它们同时出发？

赛后理清以后，这就是一次多源 BFS。先把所有安全格的距离设为 `0` 并一起放入队列，此后每个空格第一次被访问时，得到的就是它到最近安全格的最短距离。移动是双向的，所以“某个空格能否走到安全格”等价于“从安全格出发能否走到这个空格”。代码的扩展部分仍然是普通 BFS：

```python
while q:
    x, y = q.popleft()
    if dist[x][y] >= k:
        continue
    for dx, dy in directions:
        next_x = x + dx
        next_y = y + dy
        if g[next_x][next_y] != ".":
            continue
        if dist[next_x][next_y] != -1:
            continue
        dist[next_x][next_y] = dist[x][y] + 1
        ans += 1
        q.append((next_x, next_y))
```

多源 BFS 和普通 BFS 的主体其实一样，区别主要发生在初始化：普通 BFS 放入一个起点，这里把所有安全格一起放入。队列仍按距离从小到大扩展，每个格子最多进入一次，复杂度是 `O(HW)`。

今天没有往前推进主线，但两道 DP 都逼着我重新寻找“真正影响转移的状态”，D 题则暴露了另一个问题：我能想到从安全点出发，却没能把“多个起点、无权网格、限制步数”连成多源 BFS。以后看到“到某一类点的最近距离”或者“能否在 `K` 步内到达”时，我得先把方向反过来，看看能不能把所有目标点同时塞进队列。
